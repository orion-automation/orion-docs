本指南介绍如何在非容器化（Standalone）环境下配置和运行 ORION EE企业版。

## **前提条件**

> 运行 ORION EE企业版之前, 请确保你的机器已满足最低运行要求：
>
> - **Java 运行环境 (JRE)**: 支持且仅支持 Java 17 和 Java 21。请确保 `JAVA_HOME` 环境变量已正确配置。
> - CPU >= 2 核
> - RAM >= 2 GB
> - 磁盘空间 >= 10 GB（视业务和日志保留策略而定）

## 配置与准备服务

默认情况下，系统使用内置的 H2 数据库（仅供测试）。在生产环境或集群模式下，请参考以下步骤切换为企业级关系型数据库并准备启动。

### 1. 准备 JDBC 驱动
获取目标数据库的官方 JDBC 驱动程序（`.jar` 文件）。将该文件放置到解压目录下的 `configuration/userlib/` 文件夹中。系统启动时会自动加载该目录下的驱动。

### 2. 修改数据库配置
打开并编辑 `configuration/default.yml` 配置文件，找到 `spring.datasource` 配置节点，修改对应的连接参数。以 PostgreSQL 为例：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://[db-host]:[db-port]/orion_db
    driver-class-name: org.postgresql.Driver
    username: [your_db_username]
    password: [your_db_password]

```

> * 请根据实际部署环境，替换上述 `[...]` 占位符内容。
> * 数据库推荐：PostgreSQL、MySQL、Oracle。H2 仅作为本地测试使用。


## 启动服务

在配置完成后，执行名为 `start.bat`（Windows 用户）或 `start.sh`（Unix 用户）的脚本以启动核心引擎。

服务启动成功后，即可通过浏览器访问 http://localhost:8080/ 访问 Welcome Page 并使用 ORION EE企业版。

## 支持的数据库产品

ORION EE企业版全面兼容以下数据库产品的指定版本：

* **MySQL**: 8.0
* **MariaDB**: 10.6, 11.8
* **Oracle**: 19c / 23ai
* **IBM DB2**: 11.5（排除所有版本的 IBM z/OS）
* **PostgreSQL**: 15 / 16 / 17 / 18
* **Amazon Aurora PostgreSQL**: 兼容 PostgreSQL 14 / 15 / 16 / 17
* **Microsoft SQL Server**: 2017 / 2019 / 2022
* **Microsoft Azure SQL**: 需采用兼容的 SQL Server 级别（支持 SQL Server on Azure VMs, Azure SQL Managed Instance, Azure SQL Database）
* **H2**: 2.3（不推荐用于 Cluster Mode 集群模式）
