## 1. 描述

BPMN 建模器是设计模块内绘制业务流程的工作区，从业务应用的资源列表中打开。

界面分为四个部分：左侧是当前应用的文件树，中部是画布，画布右上角是工具栏，选中节点后右侧展开属性面板。编辑结果以 BPMN 2.0 模型保存回当前资源。

建模器提供两种视图档位，两档使用同一份模型，差别只在于呈现哪些入口，保存的内容完全相同。

| 档位 | 适用对象 | 呈现范围 |
| :--- | :--- | :--- |
| 设计视图 | 业务设计者 | 保留编排与表单相关入口，隐藏部署与模型源码 |
| 开发视图 | 开发与实施人员 | 呈现全部入口 |

切换档位不会重新加载编辑器，未保存的改动与撤销记录都会保留。

## 2. 界面布局

| 区域 | 位置 | 内容 |
| :--- | :--- | :--- |
| 文件树 | 左侧 | 当前业务应用的全部设计资源 |
| 画布 | 中部 | 流程图形、连线、泳道；选中节点时旁边出现快捷操作 |
| 建模托盘 | 画布左上 | 常用元素的创建入口 |
| 工具栏 | 画布右上 | 保存、视图调整、校验与仿真、面板开关、交付动作 |
| 属性面板 | 画布右侧 | 当前选中节点的全部配置项 |
| 流程文档与模型源码 | 覆盖画布 | 流程说明文档、模型源码 |
| AI 对话助手 | 画布右侧 | 与当前流程关联的对话 |

工具栏与属性面板都固定在画布范围内，不随内容滚动。属性面板的层级低于工具栏，工具栏上的提示与下拉菜单不会被面板遮挡。

## 3. 工具栏

工具栏自左至右分为七组，组间以竖线分隔，顺序固定。

### 3.1 版本与保存

| 控件 | 说明 |
| :--- | :--- |
| 当前在线版本 | 显示本次编辑所基于的版本名称。资源尚未保存到服务端时不出现 |
| 保存 | 将画布内容保存到当前版本。存在未保存改动时按钮高亮，保存过程中显示进行中状态；没有改动时不可用 |
| 另存为 | 以当前内容新增一个版本。不要求先有改动 |
| 编辑历史 | 打开历史面板，包含本机历史与在线版本两部分，详见 [7.1 编辑历史](#71-编辑历史) |

保存的快捷键为 `⌘S` / `Ctrl+S`。一次保存提交该资源的完整内容：模型与流程文档同时写入，不会只保存其中一项。

### 3.2 编辑

| 控件 | 说明 |
| :--- | :--- |
| 撤销 | 撤回上一步编辑。导入文件这类整体替换同样可以撤回 |
| 重做 | 恢复被撤回的一步 |

快捷键为 `⌘Z` / `⌘⇧Z`，Windows 下为 `Ctrl+Z` / `Ctrl+Shift+Z`，与按钮行为一致。

### 3.3 视图

| 控件 | 说明 |
| :--- | :--- |
| 缩小 | 按固定档位缩小画布 |
| 缩放比例 | 显示当前比例，仅用于查看 |
| 放大 | 按固定档位放大画布 |
| 适应窗口 | 将完整流程缩放到可视区域内 |
| 全屏编辑 | 扩大编辑区域，不改变模型。开启时按钮高亮 |
| 迷你地图 | 在画布一角显示全局缩略图，便于在大图中定位。开启时按钮高亮 |

缩放相关控件整体呈现，不会只剩其中一项。

### 3.4 校验与仿真

| 控件 | 说明 |
| :--- | :--- |
| 差异对比 | 打开并排比对视图，详见 [7.4 差异对比](#74-差异对比)。读取基线期间显示进行中状态 |
| 仿真 | 进入令牌仿真模式。该模式用于查看流程走向，不会保存任何内容 |

仿真开启后，同一组内会增加以下控件。

| 控件 | 说明 |
| :--- | :--- |
| 播放仿真 / 暂停仿真 | 开始或暂停令牌推进 |
| 重置仿真 | 清除令牌状态，回到起始节点 |
| 流程模拟日志 | 展开执行日志，逐条记录经过的节点。开启时按钮高亮 |

### 3.5 显示面板

| 控件 | 说明 |
| :--- | :--- |
| 业务架构 | 打开业务域与流程组的维护窗口，详见 [7.5 业务架构](#75-业务架构)。已配置时按钮显示标记 |
| 模型源码 | 以源码形式查看并编辑模型，详见 [7.3 模型源码](#73-模型源码)。设计视图下不提供入口 |
| 属性面板 | 打开或关闭右侧属性面板。开启时按钮高亮 |

### 3.6 交付

| 控件 | 说明 |
| :--- | :--- |
| 导入 BPMN 文件 | 选择本机 BPMN 2.0 文件并整体替换当前画布内容。不会新增资源，导入后处于未保存状态 |
| 导出 | 展开导出菜单，支持 PNG、SVG、BPMN 三种格式，并可为图片选择浅色或深色配色 |
| 部署 | 将画布当前内容下发到引擎并生成一条部署记录，详见 [7.9 部署](#79-部署)。设计视图下不提供入口 |

导出配色默认跟随界面主题。用户主动选择配色后，该选择会被保留并优先于界面主题。BPMN 格式与配色无关。

部署下发的是操作当下画布的内容，与是否已经保存无关。

### 3.7 文档与 AI

| 控件 | 说明 |
| :--- | :--- |
| 流程文档 | 打开该流程的说明文档，详见 [7.2 流程文档](#72-流程文档)。文档尚未创建时自动建立 |
| AI 对话助手 | 在右侧展开对话，详见 [7.8 AI 对话助手](#78-ai-对话助手)。与流程文档共享同一业务上下文 |

### 3.8 窄屏时的收纳

界面宽度不足时，工具栏会按以下顺序把控件逐项收入末尾的「更多操作」菜单，直到整条工具栏放得下。

1. 部署
2. 仿真、差异对比
3. 导入、导出
4. 迷你地图、全屏编辑
5. 业务架构、模型源码、属性面板
6. 适应窗口、缩放
7. 撤销、重做

| 属性 | 说明 |
| :--- | :--- |
| 始终保留 | 保存、编辑历史、流程文档、AI 对话助手 |
| 菜单顺序 | 与工具栏从左到右一致，跨组处带分隔线 |
| 使用方式 | 在菜单中点击条目，效果与直接点击工具栏按钮相同 |
| 开关类条目 | 菜单中直接显示当前状态 |
| 极窄情况 | 全部收纳后仍放不下时，工具栏改为多行排列，不会遮挡建模托盘 |

### 3.9 视图档位对工具栏的影响

| 控件 | 设计视图 | 开发视图 |
| :--- | :--- | :--- |
| 部署 | 不提供 | 提供 |
| 模型源码 | 不提供，已打开时保留退出入口 | 提供 |
| 其余控件 | 提供 | 提供 |

档位隐藏与窄屏收纳是两套独立规则：前者表示该档位用不到，后者表示当前宽度放不下。

## 4. 建模托盘

建模托盘位于画布左上角，提供常用元素的创建入口。单击或拖拽到画布均可，拖拽时目标位置会高亮提示。

### 4.1 设计视图

托盘条目按以下顺序排列。

| 条目 | 用途 |
| :--- | :--- |
| 抓手 | 平移画布，不创建元素 |
| 开始事件 | 流程入口 |
| 普通任务 | 基础活动节点 |
| 添加元素 | 打开元素挑选面板，详见 [4.3 添加元素面板](#43-添加元素面板) |
| 创建智能体任务 | 直接创建一枚已预置智能体属性的任务节点 |
| 池 / 参与者 | 承载泳道与阶段划分的容器 |
| 排他网关 | 条件分支 |
| 结束事件 | 流程终点 |

### 4.2 开发视图

开发视图在完整元素集合的基础上，追加「添加元素」与「创建智能体任务」两个入口。

### 4.3 添加元素面板

面板按类别逐层展开，顶部可切换类别。

| 类别 | 内容 | 无内容时 |
| :--- | :--- | :--- |
| 标准元素 | 任务、网关、子流程、事件四类；事件下分起点、中间捕获、中间抛出、边界、终点 | — |
| 连接器 | 当前应用已配置的连接器，选中后创建一枚已绑定该连接器的服务任务 | 提示本应用暂无连接器 |
| 增强元素 | 预留类别 | 提示无可用组件 |

| 行为 | 说明 |
| :--- | :--- |
| 层级 | 按目录逐层展开，标题栏显示当前位置，每一层都可以返回 |
| 搜索 | 跨全部类别检索，结果附所属路径；只有一个类别时不显示类别名 |
| 切换类别 | 清空当前层级与搜索内容 |
| 长列表 | 在同一面板内滚动，不会遮挡画布 |

## 5. 属性面板

属性面板位于画布右侧，宽度固定，并随画布宽度自适应上限。

| 部件 | 说明 |
| :--- | :--- |
| 标题栏 | 显示「属性面板」，右侧依次为语言开关、折叠、关闭 |
| 语言开关 | 切换面板内属性名称的显示语言，不影响站点语言。界面语言为英文时不显示 |
| 折叠 | 收起内容，保留标题栏，可随时展开 |
| 关闭 | 关闭整个面板，与工具栏上的属性面板按钮效果相同 |
| 内容 | 随选中元素类型变化，涵盖标识、人员分配、表单资源、连接器实现、输入输出映射、监听器、扩展属性等 |

面板中的资源类选项（表单、流程、决策、连接器、业务对象）来自当前应用已有的资源。某类资源为空时，对应位置显示空状态，不会隐藏该项。

## 6. 画布快捷操作

选中元素后，画布上会出现针对该元素的快捷操作。除更改元素、删除、连接之外，还提供以下入口。

| 操作 | 可用范围 | 说明 |
| :--- | :--- | :--- |
| 着色 | 任意元素 | 为元素设置颜色，作为模型的一部分保存 |
| 评论 | 任意元素 | 打开该元素的评论面板，详见 [7.7 节点评论](#77-节点评论) |
| AI 辅助配置 | 已支持 AI 能力的节点类型 | 打开该节点的 AI 配置；其他节点上不出现 |
| 打开属性面板 | 任意元素 | 打开属性面板并定位到该元素 |
| 表单 | 用户任务 | 定位到属性面板中的表单资源选项 |
| 流程 | 叫用流程 | 定位到属性面板中的被调用流程选项 |
| 决策 | 业务规则任务 | 定位到属性面板中的决策资源选项 |
| 脚本 | 脚本任务 | 语言与类型齐备时打开脚本编辑器；未齐备时定位到属性面板中尚缺的选项 |
| 连接器 | 服务任务 | 定位到属性面板中的连接器资源选项 |

连接操作位于更改元素左侧，两者归为同一组。

## 7. 浮层与视图

### 7.1 编辑历史

历史面板并列两部分，来源与作用不同。

| 部分 | 来源 | 记录方式 | 可执行操作 |
| :--- | :--- | :--- | :--- |
| 本机历史 | 当前浏览器 | 编辑过程中自动记录，也可手动保存并命名 | 载入编辑器、重命名、删除单条、清空 |
| 在线版本 | 服务端已保存的版本 | 每次保存与另存为产生 | 恢复为当前版本、重命名、删除 |

载入本机历史只改变编辑器内容，不影响服务端。恢复某个在线版本后，内容载入编辑器，此后的保存写入该版本。删除当前正在编辑的版本时，编辑器切换到剩余的最新版本，未保存的改动会丢失。

### 7.2 流程文档

| 属性 | 说明 |
| :--- | :--- |
| 内容格式 | Markdown |
| 与模型的关系 | 作为该流程的关联文档，与模型一同保存 |
| 打开行为 | 尚未创建时自动建立，已创建时直接呈现内容 |
| 编辑方式 | 编辑与预览两种状态可切换，目录由正文标题生成 |
| 未保存提示 | 存在改动时标题显示未保存标记 |
| 保存方式 | 与模型共用同一次保存，关闭文档视图不会单独提交 |
| 附带能力 | 内嵌文档 AI 助手，对话按文档分别保留 |

文档视图打开期间，画布不可编辑。

### 7.3 模型源码

以源码形式覆盖画布，可直接编辑模型定义。退出视图时内容载入画布，因此源码与图形始终对应同一份模型。设计视图下不提供入口，已打开时保留退出入口。

### 7.4 差异对比

并排两栏，左侧为比对基线，右侧为当前画布。两栏均为只读，可拖拽与缩放查看。

| 基线来源 | 说明 |
| :--- | :--- |
| 上传文件 | 选择一个本机 BPMN 文件作为基线，仅用于比对，不改变画布 |
| 本机历史 | 从本机保存过的记录中选择 |
| 在线版本 | 从服务端已保存的版本中选择 |

差异分为四类：新增、删除、修改、仅位置变化。选择基线前可随时返回选择器更换基线。

### 7.5 业务架构

维护流程的业务归属，属于资源配置信息，不写入模型本体。

| 字段 | 说明 |
| :--- | :--- |
| 业务域 | 可从流程架构目录中选择，也可直接输入 |
| 流程组 | 同上 |
| 应用 | 提交本次修改 |

窗口按流程逐个列出可维护对象；文件中没有可维护流程时给出提示。已配置时工具栏对应按钮显示标记。

### 7.6 元素文档

由快捷操作打开，用于说明单个元素的用途，随模型一起保存。与流程文档不同，它没有独立的保存动作：关闭抽屉时自动写回。

| 字段 | 说明 |
| :--- | :--- |
| 元素名称 | 取元素名称，为空时显示「无名称」 |
| 元素 ID | 元素标识，只读 |
| 正文 | Markdown，输入 `/` 可插入标题、列表、表格等 |

### 7.7 节点评论

由快捷操作打开，按元素分别存储，可逐条删除。

| 行为 | 说明 |
| :--- | :--- |
| 发送 | `Enter` |
| 换行 | `Shift+Enter` |
| 无评论时 | 显示「暂无评论」 |
| 位置 | 跟随选中元素，视图变化时同步 |

### 7.8 AI 对话助手

在画布右侧展开，画布宽度相应收缩，不覆盖画布内容。

| 属性 | 说明 |
| :--- | :--- |
| 宽度 | 可拖拽调整 |
| 铺满 | 支持铺满模式，此时宽度自适应，不再拖拽 |
| 与其它 AI 的关系 | 与流程文档 AI、节点 AI 互斥，同一时刻仅开启一个 |
| 历史记录 | 按资源分别保留 |

### 7.9 部署

将画布内容下发至引擎，生成一条部署记录。提交规则与运行模块的「新建部署」一致。

| 属性 | 说明 |
| :--- | :--- |
| 下发内容 | 操作当下的画布内容 |
| 可见性 | 设计视图下不提供该入口 |
| 后续 | 部署完成后可在运行模块查看该流程 |

## 8. 快捷键

| 快捷键 | 生效范围 | 行为 |
| :--- | :--- | :--- |
| `⌘S` / `Ctrl+S` | 业务应用页面 | 保存当前文件 |
| `⌘Z` / `Ctrl+Z` | 画布 | 撤销 |
| `⌘⇧Z` / `Ctrl+Shift+Z` | 画布 | 重做 |
| `Esc` | 浮层 | 关闭当前打开的窗口、菜单或编辑器 |

## 9. 行为与约束

| 类型 | 说明 |
| :--- | :--- |
| 必须 | 保存提交该资源的完整内容，模型与流程文档同时写入 |
| 必须 | 导入 BPMN 文件为整体覆盖，原有内容被替换，此前可撤销的步骤被清空；导入本身可以撤销，返回导入前的状态 |
| 必须 | 部署下发操作当下的画布内容，与是否已保存无关 |
| 必须 | 设计视图只减少可见入口，不改变保存的模型内容与保存方式 |
| 不支持 | 生成对外分享链接。查看权限由业务应用的成员权限决定 |
| 不支持 | 单独切换画布主题。画布跟随站点深浅色，导出配色在导出菜单内选择 |
| 注意 | 工具栏收纳到最小后仍需一定宽度，画布更窄时改为多行排列 |
| 注意 | 尚未保存到服务端的资源没有在线版本，版本标识与在线版本部分都不出现 |
