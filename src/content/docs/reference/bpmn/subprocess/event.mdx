## 1. 描述 (Description)

事件子流程（Event Subprocess）是一种由特定事件触发的特殊子流程。它可以被添加在顶级流程级别，也可以嵌套在任何普通的子流程级别中。

在 ORION 平台中，事件子流程是处理局部异常（如错误处理）、并发事务（如随时接收取消信号）以及 SLA 超时监控的核心架构组件。


## 2. 核心架构约束 (Core Architectural Constraints)

事件子流程在拓扑结构上具有独特的物理限制：

| 约束类型 | 事实描述与架构限制 |
| :--- | :--- |
| **触发入口** | 必须通过特定的开始事件（Start Event）来触发。支持的类型包括：消息 (Message)、错误 (Error)、信号 (Signal)、定时器 (Timer) 或补偿 (Compensation) 事件。绝对不支持空开始事件 (None Start Event)。 |
| **连线隔离** | 事件子流程绝对不能有任何输入或输出的顺序流 (Sequence Flows)。因为它是由事件隐式触发的，外部的物理连线在此毫无意义。 |
| **XML 标识** | 在底层模型中，除了像普通子流程一样定义外，必须强制包含 `triggeredByEvent="true"` 属性。 |


## 3. 生命周期与中断机制 (Lifecycle & Interruption)

事件子流程的事件订阅生命周期与其宿主作用域（Host Scope，即它所在的流程或父子流程）严格绑定：
* **订阅与销毁**：当宿主作用域被创建时，引擎会自动创建对该事件子流程启动事件的订阅；当宿主作用域结束时，该订阅也会被安全移除。

在触发时，它分为两种截然不同的执行模式，由其开始事件的属性决定：

### 3.1 中断型 (Interrupting)
* **系统行为**：一旦触发，引擎将强制取消（Cancel）当前宿主作用域内的所有活跃执行流。
* **触发频率**：对于宿主作用域的每一次激活，中断型事件子流程只能被触发一次。
* **完结状态**：当中断型事件子流程执行结束时，当前的宿主作用域也将随之宣告结束。

### 3.2 非中断型 (Non-interrupting)
* **系统行为**：触发后，宿主作用域的原有活动继续运行，引擎会派生出一个全新的并发执行流（Concurrent Execution）来运行事件子流程。
* **触发频率**：在宿主作用域活跃期间，它可以被多次触发，生成多个并行的子流程实例。
* **完结状态**：当它执行结束时，仅代表这条派生的并发执行流结束，宿主作用域的主干不受影响。


## 4. 架构边界：事件子流程 vs. 边界事件 (Event Subprocess vs. Boundary Event)

如果将事件子流程添加在一个嵌入式子流程内部，它就成为了附加在该子流程外部的“边界事件 (Boundary Event)”的一种架构替代方案。在企业级实战中，选择哪种模式取决于对**变量上下文**的要求：

* **局部变量保留 (Event Subprocess)**：事件子流程与其宿主在同一个执行作用域内运行。这意味着它可以直接访问宿主子流程内部创建的所有局部变量。事件完全由该子流程内部闭环处理。
* **变量销毁 (Boundary Event)**：如果使用边界事件捕获异常，执行流在离开边界事件时，引擎会直接销毁原本用于执行子流程的作用域。这意味着子流程内部创建的所有局部变量将彻底丢失，无法被后续节点访问。事件的控制权被移交给了父级流程来处理。

通过理解这层物理差异，架构师可以更精准地决定是采用边界事件进行全局粗粒度拦截，还是采用事件子流程进行保留上下文的精细化处理。


## 5. 引擎级技术属性 (Engine Execution Properties)

事件子流程支持以下 ORION 引擎底层扩展属性：

| 属性名称 (UI Label) | 对应 XML 扩展 | 约束与事实描述 |
| :--- | :--- | :--- |
| **Async Before/After** | `camunda:async*` | 强制切断数据库事务。建议在复杂的异常处理链路中开启。 |
| **Exclusive** | `camunda:exclusive` | （仅在开启 Async 时生效）确保异步 Job 的独占执行。 |
| **Job Priority** | `camunda:jobPriority` | 设定异步任务的队列优先级。 |
| **Retry Time Cycle** | `camunda:failedJobRetryTimeCycle` | 设定执行失败时的重试策略。 |
| **Input/Output** | `camunda:inputOutput` | 显式声明数据映射。 |
