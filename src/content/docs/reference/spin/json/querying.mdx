## 1. 概述

SPIN JSON 数据类型支持通过 JSONPath 查询语言进行数据检索。

JSONPath 提供了声明式的查询能力，允许使用路径表达式从深层嵌套的 JSON 结构中定位节点、提取集合或根据业务规则进行条件过滤。这是处理复杂 JSON 载荷的高效方案。

## 2. 基础查询模式

使用 `.jsonPath(String path)` 方法发起查询。查询后，必须调用具体的转换方法（如 `.element()` 或 `.elementList()`）将查询结果解析为可操作的 SPIN 对象或集合。

测试使用的 JSON 数据结构如下：
```json
{
  "child": [
    {"id": 1, "name": "Lucy", "sex": "female"},
    {"id": 2, "name": "Tracy", "sex": "female"}
  ],
  "number": 1,
  "boolean": true
}

```

### 2.1 单个节点查询

用于精准定位 JSON 树中的某个特定节点。

```java
import static org.camunda.spin.Spin.JSON;

SpinJsonNode child = JSON(json).jsonPath("$.child[0]").element();

```

### 2.2 节点列表查询

用于提取符合路径描述的所有节点集合，返回 `SpinList<SpinJsonNode>` 类型。

```java
import static org.camunda.spin.Spin.JSON;

SpinList<SpinJsonNode> childs = JSON(json).jsonPath("$.child").elementList();

```

## 3. 强类型值提取

查询路径表达式后，SPIN 支持直接获取符合特定 Java 类型的结果。

### 3.1 字符串提取

使用 `.stringValue()` 提取特定路径下的字符串。

```java
import static org.camunda.spin.Spin.JSON;

String value = JSON(json).jsonPath("$.child[0].name").stringValue();

```

### 3.2 数值提取

使用 `.numberValue()` 提取路径下的数值，返回 `Double`。

```java
import static org.camunda.spin.Spin.JSON;

Double count = JSON(json).jsonPath("$.number").numberValue();

```

### 3.3 布尔值提取

使用 `.boolValue()` 提取路径下的逻辑值。

```java
import static org.camunda.spin.Spin.JSON;

Boolean exists = JSON(json).jsonPath("$.boolean").boolValue();

```

## 4. 过滤查询

JSONPath 支持在路径中使用 `?()` 语法进行条件过滤。

### 4.1 过滤语法规范

* **逻辑位置**: 过滤表达式必须编写在括号 `()` 内。
* **物理约束**: 过滤表达式内部**绝对禁止使用双引号 (`"`)**。必须全部使用单引号 (`'`)，否则将导致查询解析异常。

### 4.2 过滤查询示例

从下属列表中筛选所有性别为 'female' 的记录：

```java
import static org.camunda.spin.Spin.JSON;

SpinList<SpinJsonNode> girls = JSON(json).jsonPath("$.child[?(@.sex == 'female')]").elementList();

```


## 5. 性能与约束

**性能成本**: 相比直接使用 `.prop()` 属性访问，JSONPath 解析器在执行时需要额外的开销来计算路径。在低延迟要求的服务任务逻辑中，若路径深度固定且已知，优先使用 `.prop()` 访问。
**空结果处理**: 若 JSONPath 查询未能匹配到任何节点，方法可能返回空结果，或在调用取值方法时抛出异常。务必在执行查询前确保数据结构符合预期，或通过 `try-catch` 进行运行时防御。
**双引号约束**: 再次强调，过滤表达式中的属性对比值必须使用单引号，这是该库在该引擎实现层面的强制规范。
