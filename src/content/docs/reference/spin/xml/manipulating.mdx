## 1. 属性

### 1.1 检查属性

| 方法 | 说明 |
| :--- | :--- |
| `hasAttr(name)` | 是否存在不带命名空间的同名属性 |
| `hasAttrNs(uri, name)` | 是否存在指定命名空间下的同名属性 |

```java
import static org.camunda.spin.Spin.XML;

String xml = "<order xmlns:cam=\"http://example.com\" id=\"order1\" cam:name=\"name\" />";

XML(xml).hasAttr("id");                                   // true
XML(xml).hasAttrNs("http://example.com", "name");         // true
```

### 1.2 读取属性

`attr(name)` 返回属性对象，再调 `value()` 取值。带命名空间的属性用 `attrNs(uri, name)`。

```java
SpinXmlAttribute attribute = XML(xml).attr("id");
String id = attribute.value();
```

注意 `hasAttrNs(uri, "name")` 与 `attr("name")` 不是一回事：前者认命名空间，后者只认无命名空间的属性。

### 1.3 列出属性

| 方法 | 返回 |
| :--- | :--- |
| `attrs()` | 全部属性 |
| `attrs(uri)` | 指定命名空间下的属性 |
| `attrNames()` | 全部属性的名称 |
| `attrNames(uri)` | 指定命名空间下的属性名称 |

### 1.4 写入属性

既可以在元素上设，也可以在属性对象上设，两种写法等价。

```java
XML(xml).attr("id", "newId");

SpinXmlAttribute attribute = XML(xml).attr("id");
attribute.value("newId");
```

带命名空间时用 `attrNs(uri, name, value)`。

### 1.5 删除属性

```java
SpinXmlDomElement element = XML(xml).removeAttr("id");
```

也可以在属性对象上调用 `remove()`，返回被操作的元素。带命名空间时用 `removeAttrNs(uri, name)`。

## 2. 文本内容

`textContent()` 读取元素的文本，传入参数则写入。

```java
SpinXmlDomElement element = XML("<customer>Foo</customer>");
String text = element.textContent();   // "Foo"
element.textContent("Bar");
```

`textContent()` 取的是元素下全部文本的拼接，包含子元素里的文本。只想取直接文本时，要用子元素或查询来定位。

## 3. 子元素

### 3.1 读取子元素

| 方法 | 返回 |
| :--- | :--- |
| `childElement(name)` | 第一个同名子元素 |
| `childElement(uri, name)` | 第一个指定命名空间下的同名子元素 |
| `childElements(name)` | 全部同名子元素 |
| `childElements(uri, name)` | 指定命名空间下的全部同名子元素 |

```java
String xml = "<order xmlns:cam=\"http://example.com\">"
    + "<date/><cam:due/><item/><item/></order>";

SpinXmlDomElement date = XML(xml).childElement("date");
SpinXmlDomElement due = XML(xml).childElement("http://example.com", "due");
SpinCollection<SpinXmlDomElement> items = XML(xml).childElements("item");
```

`childElement` 只找直接子元素，不会向下递归。要按层级或条件取节点，用 [XPath 查询](/reference/spin/xml/querying/)。

### 3.2 追加子元素

`append` 接受一个或多个元素。

```java
SpinXmlTreeElement root = XML("<root/>");
root.append(XML("<child/>"), XML("<child/>"));
```

参数里的元素必须能挂在这个父元素下——已经挂在别处的元素要先脱离或复制。

### 3.3 删除子元素

`remove` 接受单个或多个子元素。

```java
SpinXmlTreeElement root = XML("<root><child/><child/><child/></root>");
root.remove(root.childElements("child"));
```

### 3.4 替换元素

| 方法 | 作用 |
| :--- | :--- |
| `replaceChild(旧元素, 新元素)` | 在父元素上替换某个子元素 |
| `replace(新元素)` | 在元素自身的位置上替换自己 |

```java
SpinXmlTreeElement root = XML("<root><date/><order/></root>");
root.replaceChild(root.childElement("date"), XML("<child/>"));
root.childElement("order").replace(XML("<child/>"));
```

两种方法都返回替换后的元素，原来的元素不再属于这棵树。

## 4. 在脚本语言中操作

脚本语言里的方法与 Java 同名同义，属性值读取要多一步 `.value()`。

```python
xml = '<order id="1231"><item id="1"/></order>'

assert S(xml).hasAttr('id')
order_id = S(xml).attr('id').value()

item_id = S(xml).childElement('item').attr('id').value()
```

## 5. 约束

| 项 | 说明 |
| :--- | :--- |
| 方法不能混用 | 属性方法只在元素上可用，`value()` 只在属性上可用 |
| 命名空间必须显式给出 | 不带 `Ns` 的方法不会匹配任何带命名空间的名称 |
| 修改是就地生效的 | 操作返回的仍是同一棵树，不需要重新解析 |
| 只在内存中生效 | 修改不会自动写回流程变量，需要显式赋值 |
