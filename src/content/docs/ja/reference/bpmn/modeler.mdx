## 1. 概要

BPMN モデラーは、設計モジュールの中で業務プロセスを描くためのワークスペースです。業務アプリのリソース一覧から開きます。

画面は四つの部分で構成されます。左が現在のアプリのファイルツリー、中央がキャンバス、キャンバス右上がツールバー、要素を選ぶと右側にプロパティパネルが開きます。編集結果は BPMN 2.0 モデルとして現在のリソースに保存されます。

表示モードは二つあります。どちらも同じモデルを扱い、保存される内容もまったく同じで、違いは表示される操作だけです。

| モード | 対象 | 表示される範囲 |
| :--- | :--- | :--- |
| 設計ビュー | 業務設計者 | オーケストレーションとフォームに関わる操作。デプロイとモデルソースは表示されません |
| 開発ビュー | 開発・導入担当者 | すべての操作 |

モードを切り替えてもエディターは再読み込みされません。未保存の変更と元に戻す履歴はそのまま残ります。

## 2. 画面構成

| 領域 | 位置 | 内容 |
| :--- | :--- | :--- |
| ファイルツリー | 左 | 現在の業務アプリの設計リソース一式 |
| キャンバス | 中央 | 図形、接続線、レーン。要素を選ぶと横にクイック操作が現れます |
| 要素パレット | キャンバス左上 | よく使う要素を作るための入口 |
| ツールバー | キャンバス右上 | 保存、表示の調整、検証とシミュレーション、パネルの表示切替、受け渡しの操作 |
| プロパティパネル | キャンバス右 | 選択中の要素の設定一式 |
| プロセスドキュメントとモデルソース | キャンバスの上に重ねて表示 | プロセスの説明ドキュメントとモデルソース |
| AI アシスタント | キャンバス右 | 現在のプロセスに紐づく会話 |

ツールバーとプロパティパネルはキャンバス内に固定され、内容と一緒にはスクロールしません。プロパティパネルはツールバーより下の層にあるため、ツールバーのツールチップやドロップダウンメニューがパネルに隠れることはありません。

## 3. ツールバー

ツールバーは左から右へ七つのグループに分かれ、グループの間は縦線で区切られます。並び順は固定です。

### 3.1 バージョンと保存

| 操作 | 説明 |
| :--- | :--- |
| 現在のオンライン版 | 今回の編集がどの版を元にしているかを表示します。リソースがサーバーに保存されるまでは表示されません |
| 保存 | キャンバスの内容を現在の版に保存します。未保存の変更があるとボタンが強調され、保存中は進行中の状態になります。変更がないときは使えません |
| 名前を付けて保存 | 現在の内容で新しい版を作ります。事前の変更は必要ありません |
| 履歴 | 履歴パネルを開きます。この端末の履歴とオンライン版の二部構成です。詳しくは [7.1 履歴](#71-履歴) を参照してください |

保存のショートカットは `⌘S` / `Ctrl+S` です。1 回の保存でそのリソースの内容全体を送り、モデルとプロセスドキュメントが同時に書き込まれます。片方だけが保存されることはありません。

### 3.2 編集

| 操作 | 説明 |
| :--- | :--- |
| 元に戻す | 直前の編集を取り消します。ファイルのインポートのように全体を置き換える操作も同じように取り消せます |
| やり直す | 取り消した操作をやり直します |

ショートカットは `⌘Z` / `⌘⇧Z`、Windows では `Ctrl+Z` / `Ctrl+Shift+Z` で、ボタンと同じ動作です。

### 3.3 表示

| 操作 | 説明 |
| :--- | :--- |
| 縮小 | 決まった段階ずつキャンバスを縮小します |
| 倍率 | 現在の倍率を表示します。表示のみです |
| 拡大 | 決まった段階ずつキャンバスを拡大します |
| ビューポートに合わせる | プロセス全体を表示領域に収めます |
| 全画面編集 | 編集領域を広げます。モデルは変わりません。有効な間はボタンが強調されます |
| ミニマップ | キャンバスの隅に全体の縮小図を表示し、大きな図でも位置を掴めるようにします。有効な間はボタンが強調されます |

拡大・縮小に関わる操作はまとめて表示され、どれか一つだけになることはありません。

### 3.4 検証とシミュレーション

| 操作 | 説明 |
| :--- | :--- |
| 差分比較 | 左右に並べた比較画面を開きます。詳しくは [7.4 差分比較](#74-差分比較) を参照してください。ベースラインの読み込み中は進行中の状態になります |
| シミュレーション | トークンシミュレーションに入ります。プロセスの流れを確認するためのモードで、内容は一切保存されません |

シミュレーションを開始すると、同じグループに次の操作が加わります。

| 操作 | 説明 |
| :--- | :--- |
| シミュレーション再生 / 一時停止 | トークンの進行を開始または一時停止します |
| シミュレーションリセット | トークンの状態を消し、開始イベントに戻します |
| シミュレーションログ | 実行ログを展開します。通った要素が一件ずつ記録されます。開いている間はボタンが強調されます |

### 3.5 パネル表示

| 操作 | 説明 |
| :--- | :--- |
| ビジネスアーキテクチャ | ビジネスドメインとプロセスグループを管理する画面を開きます。詳しくは [7.5 ビジネスアーキテクチャ](#75-ビジネスアーキテクチャ) を参照してください。設定済みの場合はボタンに印が付きます |
| モデルソース | モデルをソースの形で表示・編集します。詳しくは [7.3 モデルソース](#73-モデルソース) を参照してください。設計ビューでは表示されません |
| プロパティ | 右側のプロパティパネルを開閉します。開いている間はボタンが強調されます |

### 3.6 受け渡し

| 操作 | 説明 |
| :--- | :--- |
| BPMN ファイルをインポート | 手元の BPMN 2.0 ファイルを選び、キャンバスの内容を丸ごと置き換えます。新しいリソースは作られず、インポート後は未保存の状態になります |
| エクスポート | 書き出しメニューを開きます。PNG、SVG、BPMN の三形式に対応し、画像はライトまたはダークの配色を選べます |
| デプロイ | キャンバスの内容をエンジンに送り、デプロイ記録を一件作ります。詳しくは [7.9 デプロイ](#79-デプロイ) を参照してください。設計ビューでは表示されません |

書き出しの配色は、自分で選ぶまでは画面のテーマに従います。選んだ配色は保持され、以後はテーマより優先されます。BPMN 形式は配色の影響を受けません。

デプロイで送られるのは操作した時点のキャンバスの内容で、保存済みかどうかは関係ありません。

### 3.7 ドキュメントと AI

| 操作 | 説明 |
| :--- | :--- |
| プロセスドキュメント | このプロセスの説明ドキュメントを開きます。詳しくは [7.2 プロセスドキュメント](#72-プロセスドキュメント) を参照してください。まだ無い場合は自動で作成されます |
| AI アシスタント | 右側に会話を展開します。詳しくは [7.8 AI アシスタント](#78-ai-アシスタント) を参照してください。プロセスドキュメントと同じ業務コンテキストを共有します |

### 3.8 幅が足りないとき

画面の幅が足りないとき、ツールバーは次の順に操作を右端の「その他の操作」メニューへ移し、全体が収まるまで続けます。

1. デプロイ
2. シミュレーション、差分比較
3. インポート、エクスポート
4. ミニマップ、全画面編集
5. ビジネスアーキテクチャ、モデルソース、プロパティ
6. ビューポートに合わせる、拡大・縮小
7. 元に戻す、やり直す

| 項目 | 説明 |
| :--- | :--- |
| 常に残るもの | 保存、履歴、プロセスドキュメント、AI アシスタント |
| メニューの順序 | ツールバーの左から右と同じで、グループの変わり目に区切り線が入ります |
| 使い方 | メニューの項目をクリックすると、ツールバーのボタンを押したのと同じ結果になります |
| 切り替え項目 | 現在の状態がメニューにそのまま表示されます |
| 極端に狭い場合 | すべて移しても収まらないときは、ツールバーが複数行に折り返します。要素パレットを覆うことはありません |

### 3.9 表示モードとツールバー

| 操作 | 設計ビュー | 開発ビュー |
| :--- | :--- | :--- |
| デプロイ | 表示されません | 表示されます |
| モデルソース | 表示されません。すでに開いている場合は閉じる操作だけが残ります | 表示されます |
| その他 | 表示されます | 表示されます |

モードによる非表示と、幅が足りないための格納は別々のルールです。前者はそのモードでは不要という意味、後者は今の幅では収まらないという意味です。

## 4. 要素パレット

要素パレットはキャンバスの左上にあり、よく使う要素を作る入口です。クリックしても、キャンバスへドラッグしても作成できます。ドラッグ中は落とす位置が強調されます。

### 4.1 設計ビュー

パレットの項目は次の順に並びます。

| 項目 | 用途 |
| :--- | :--- |
| ハンドツール | 要素を作らずにキャンバスを移動します |
| 開始イベント | プロセスの入口 |
| タスク | 基本的な作業ノード |
| 要素を追加 | 要素を選ぶパネルを開きます。詳しくは [4.3 要素の追加パネル](#43-要素の追加パネル) を参照してください |
| エージェントタスクを作成 | エージェントの属性が設定済みのタスクを直接作ります |
| プール/参加者 | レーンと段階を載せる入れ物 |
| 排他ゲートウェイ | 条件分岐 |
| 終了イベント | プロセスの終点 |

### 4.2 開発ビュー

開発ビューでは、要素一式に加えて「要素を追加」と「エージェントタスクを作成」の二つが増えます。

### 4.3 要素の追加パネル

パネルはカテゴリごとに階層をたどって開き、上部でカテゴリを切り替えられます。

| カテゴリ | 内容 | 空のとき |
| :--- | :--- | :--- |
| 標準要素 | タスク、ゲートウェイ、サブプロセス、イベントの四種類。イベントは開始、中間捕捉、中間スロー、境界、終了に分かれます | — |
| コネクター | このアプリで設定済みのコネクター。選ぶと、そのコネクターに紐づいたサービスを作ります | このアプリにコネクターはまだありません |
| 拡張要素 | 予約カテゴリ | 利用可能なコンポーネントがありません |

| 動作 | 説明 |
| :--- | :--- |
| 階層 | ディレクトリのように一層ずつ開きます。現在地はタイトルバーに表示され、どの層からでも戻れます |
| 検索 | すべてのカテゴリを横断して検索し、結果には所属する階層を添えます。カテゴリが一つだけのときはカテゴリ名を出しません |
| カテゴリの切り替え | 現在の階層と検索内容を消します |
| 長いリスト | 同じパネル内でスクロールし、キャンバスを覆いません |

## 5. プロパティパネル

プロパティパネルはキャンバスの右側にあり、幅は固定で、キャンバスの幅に合わせて上限が変わります。

| 部分 | 説明 |
| :--- | :--- |
| タイトルバー | 「プロパティ」と表示し、右へ順に言語の切り替え、折りたたみ、閉じるが並びます |
| 言語の切り替え | パネル内のプロパティ名の表示言語を切り替えます。サイトの言語は変わりません。画面の言語が英語のときは表示されません |
| 折りたたみ | 中身を畳み、タイトルバーだけを残します。いつでも戻せます |
| 閉じる | パネル全体を閉じます。ツールバーのプロパティボタンと同じ結果になります |
| 内容 | 選択した要素の種類によって変わり、識別子、担当の割り当て、フォームのリソース、コネクターの実装、入出力のマッピング、リスナー、拡張プロパティなどを扱います |

パネル内のリソース系の選択肢（フォーム、プロセス、決定、コネクター、ビジネスオブジェクト）は、現在のアプリにあるリソースから選びます。ある種別が空のときは、その項目を隠さずに空の状態を表示します。

## 6. キャンバスのクイック操作

要素を選ぶと、その要素向けの操作がキャンバスに現れます。要素を変更、削除、接続のほかに、次の入口があります。

| 操作 | 使える対象 | 説明 |
| :--- | :--- | :--- |
| 色を設定 | すべての要素 | 要素に色を付けます。モデルの一部として保存されます |
| ノードコメント | すべての要素 | その要素のコメントパネルを開きます。詳しくは [7.7 ノードコメント](#77-ノードコメント) を参照してください |
| AI 設定 | AI に対応した要素の種類 | その要素の AI 設定を開きます。他の要素には表示されません |
| プロパティを開く | すべての要素 | プロパティパネルを開き、その要素の位置へ移動します |
| フォーム | ユーザータスク | プロパティパネルのフォームのリソース項目へ移動します |
| プロセス | コールアクティビティ | プロパティパネルの呼び出すプロセスの項目へ移動します |
| 決定 | ビジネスルールタスク | プロパティパネルの決定のリソース項目へ移動します |
| スクリプト | スクリプトタスク | 言語と種類がそろっていればスクリプトエディターを開きます。そろっていなければ、足りない項目へ移動します |
| コネクター | サービス | プロパティパネルのコネクターのリソース項目へ移動します |

接続の操作は「要素を変更」の左にあり、この二つで一つのグループになります。

## 7. パネルと画面

### 7.1 履歴

履歴パネルは二つの部分を並べて表示します。出どころも役割も異なります。

| 部分 | 出どころ | 記録のされ方 | できること |
| :--- | :--- | :--- | :--- |
| この端末の履歴 | 現在のブラウザー | 編集中に自動で記録され、手動で名前を付けて保存もできます | エディターに読み込む、名前を変更、一件削除、すべて消去 |
| オンライン版 | サーバーに保存済みの版 | 保存と名前を付けて保存のたびに作られます | 現在の版に戻す、名前を変更、削除 |

この端末の履歴を読み込んでも変わるのはエディターの中身だけで、サーバーには影響しません。オンライン版に戻すとその内容がエディターに読み込まれ、以後の保存はその版に書き込まれます。編集中の版を削除すると、残っている中で最新の版に切り替わり、未保存の変更は失われます。

### 7.2 プロセスドキュメント

| 項目 | 説明 |
| :--- | :--- |
| 形式 | Markdown |
| モデルとの関係 | このプロセスに付く説明ドキュメントで、モデルと一緒に保存されます |
| 開いたときの動作 | まだ無ければ自動で作成し、あれば内容をそのまま表示します |
| 編集 | 編集とプレビューを切り替えられます。目次は見出しから作られます |
| 未保存の表示 | 変更があるとタイトルに未保存の印が付きます |
| 保存 | モデルと同じ保存で一緒に送られます。ドキュメント画面を閉じても単独では送信されません |
| 付属の機能 | ドキュメント用の AI アシスタントを内蔵し、会話はドキュメントごとに残ります |

ドキュメント画面を開いている間は、キャンバスを編集できません。

### 7.3 モデルソース

モデル定義をソースの形でキャンバスに重ねて表示し、そのまま編集できます。画面を閉じると内容がキャンバスに読み込まれるため、ソースと図は常に同じモデルを指します。設計ビューでは表示されませんが、すでに開いている場合は閉じる操作だけが残ります。

### 7.4 差分比較

左右二列で、左が比較のベースライン、右が現在のキャンバスです。どちらも読み取り専用で、移動と拡大縮小ができます。

| ベースラインの出どころ | 説明 |
| :--- | :--- |
| ファイルをアップロード | 手元の BPMN ファイルをベースラインにします。比較に使うだけで、キャンバスは変わりません |
| この端末の履歴 | ローカルに保存した記録から選びます |
| オンライン版 | サーバーに保存済みの版から選びます |

差分は四種類です。追加、削除、変更、位置だけの変更。ベースラインを選ぶまでは、いつでも選択画面に戻って選び直せます。

### 7.5 ビジネスアーキテクチャ

プロセスの業務上の所属を管理します。リソースの設定情報であり、モデル本体には書き込まれません。

| 項目 | 説明 |
| :--- | :--- |
| ビジネスドメイン | プロセスアーキテクチャの一覧から選ぶことも、直接入力することもできます |
| プロセスグループ | 同上 |
| 適用 | 今回の変更を送信します |

画面には管理できる対象がプロセスごとに並び、ファイル内に管理できるプロセスが無いときはその旨を表示します。設定済みの場合、ツールバーの対応するボタンに印が付きます。

### 7.6 要素ドキュメント

クイック操作から開き、一つの要素の役割を説明します。モデルと一緒に保存されます。プロセスドキュメントと違い、独立した保存操作はありません。ドロワーを閉じたときに書き戻されます。

| 項目 | 説明 |
| :--- | :--- |
| 要素名 | 要素の名前を使います。空のときは「名称未設定」と表示します |
| 要素 ID | 要素の識別子です。読み取り専用です |
| 本文 | Markdown です。`/` を入力すると見出し、リスト、表などを挿入できます |

### 7.7 ノードコメント

クイック操作から開き、要素ごとに保存されます。一件ずつ削除できます。

| 動作 | 説明 |
| :--- | :--- |
| 送信 | `Enter` |
| 改行 | `Shift+Enter` |
| コメントが無いとき | 「コメントはありません」と表示します |
| 位置 | 選択中の要素に追従し、表示が変わると一緒に動きます |

### 7.8 AI アシスタント

キャンバスの右側に展開し、キャンバスの幅はその分だけ狭くなります。内容を覆うことはありません。

| 項目 | 説明 |
| :--- | :--- |
| 幅 | ドラッグで調整できます |
| 全幅表示 | 全幅表示に対応し、その間は幅が自動になりドラッグできません |
| 他の AI との関係 | プロセスドキュメントの AI と要素の AI とは排他で、同時に開けるのは一つだけです |
| 履歴 | リソースごとに残ります |

### 7.9 デプロイ

キャンバスの内容をエンジンに送り、デプロイ記録を一件作ります。送信のルールは実行モジュールの「新規デプロイ」と同じです。

| 項目 | 説明 |
| :--- | :--- |
| 送る内容 | 操作した時点のキャンバスの内容 |
| 表示 | 設計ビューでは表示されません |
| その後 | デプロイが終わると、実行モジュールでこのプロセスを確認できます |

## 8. ショートカット

| ショートカット | 有効な範囲 | 動作 |
| :--- | :--- | :--- |
| `⌘S` / `Ctrl+S` | 業務アプリの画面 | 現在のファイルを保存します |
| `⌘Z` / `Ctrl+Z` | キャンバス | 元に戻す |
| `⌘⇧Z` / `Ctrl+Shift+Z` | キャンバス | やり直す |
| `Esc` | パネル | 開いている画面、メニュー、エディターを閉じます |

## 9. 動作と制約

| 種類 | 説明 |
| :--- | :--- |
| 必須 | 保存はそのリソースの内容全体を送り、モデルとプロセスドキュメントを同時に書き込みます |
| 必須 | BPMN ファイルのインポートは全体を置き換え、それまで取り消せた操作は消えます。インポート自体は取り消せて、インポート前の状態に戻ります |
| 必須 | デプロイは操作した時点のキャンバスの内容を送り、保存済みかどうかは関係ありません |
| 必須 | 設計ビューは見える入口を減らすだけで、保存されるモデルの内容も保存のしかたも変えません |
| 非対応 | 外部向けの共有リンクの生成。閲覧できる範囲は業務アプリのメンバー権限で決まります |
| 非対応 | キャンバスのテーマだけを切り替えること。キャンバスは画面のライト・ダークに従い、書き出しの配色は書き出しメニューで選びます |
| 注意 | ツールバーは最小まで畳んでも一定の幅が必要です。さらに狭いと複数行に折り返します |
| 注意 | サーバーに一度も保存していないリソースにはオンライン版が無いため、版の表示もオンライン版の部分も出ません |
