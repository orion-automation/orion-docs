租户用于隔离各业务单元的数据。本篇覆盖租户的创建、成员关系维护与删除。

## 1. 新建租户

**前置条件**
* 已进入组织模块，并在左侧导航选择「租户」。

**操作步骤**
1. 点击列表右上角的「新建租户」。
2. 填写 **租户 ID**：创建后不能修改，且必须唯一；对话框会实时检查是否已被占用。
3. 填写 **名称**（必填项）。
4. 点击「创建」提交。

**预期结果**
* 列表出现新租户，提示「租户 `{租户 ID}` 已创建」。

## 2. 批量导入租户

**前置条件**
* 已准备好 Excel 文件（`.xlsx` 或 `.xlsm`；`.xls` 请先另存为 `.xlsx`）。

**操作步骤**
1. 点击列表右上角的「导入」。
2. 没有现成表格时，先点击「下载模板」。
3. 表头需包含：**租户 ID** 与 **名称**，两者都必填。
4. 选择文件并核对校验结果，点击「导入 N 个」开始创建。

**预期结果**
* 校验规则与新建一致：租户 ID 不能为空、只能包含字母、数字且不能以 `-` 开头、不能与已有租户重复；名称不能为空。
* 有问题的行被跳过，其余照常创建；完成后报告成功、失败与跳过的行数。

## 3. 添加与移出租户成员

**前置条件**
* 目标用户或用户组已存在；若尚未创建，请先按 [如何管理组织用户](/howto/admin/user/) 与 [如何管理用户组与成员](/howto/admin/group/) 建好。

**操作步骤**
1. 点击列表中的目标租户，右侧滑出「租户详情」。
2. 切换「用户」页签，点击「添加用户」，输入 ID 或名称查找（名称匹配区分大小写），可多选后点击「加入（N）」。
3. 切换「用户组」页签，用同样方式添加用户组。
4. 需要移出时，点击该成员行的「移出」，在确认框中确认。

**预期结果**
* 加入后提示「已将 `{成员}` 添加进本租户」；移出后提示「已把「`{成员}`」从本租户移出」。
* 被移出的租户本身不会被删除，也不影响其他关系；需要时可重新添加。

### 批量导入用户

**操作步骤**
1. 在「用户」页签点击「导入用户」。
2. 没有表格时先「下载模板」；表头只需一列：**用户 ID**（填 ID，不是邮箱）。
3. 选择文件后点击「导入 N 个」。

**预期结果**
* 这里只建立归属关系，不会新建用户；用户必须已经存在。
* 找不到的用户被跳过，对话框给出清单，可「复制清单」或「下载清单」，去用户列表建好后再回来导一次。

## 4. 筛选与排序租户

**操作步骤**
1. 点击列表右上角的「筛选」，按需填写：租户 ID、名称、名称包含（可勾选区分大小写）、所属用户（用户 ID）、所属用户组（组 ID）。
2. 需要连该用户所在用户组的租户一起查时，先填「所属用户」，再勾选「也包含该用户所在用户组的租户」。
3. 点击「重置」清空条件；点击列头可按该列排序。

**预期结果**
* 列表只显示符合条件的租户；修改条件后列表自动刷新。

## 5. 删除租户

**前置条件**
* 删除前建议先确认租户下的成员已迁出，或确认这些成员不再需要该租户的数据隔离。

**操作步骤**
1. 在列表中点击目标租户行右侧的「更多操作」菜单。
2. 选择「删除租户」，在确认框中确认。

**预期结果**
* 提示「租户 `{租户 ID}` 已删除」，列表移除该行。若提示该租户已不存在，刷新列表即可。
