系统页分两个标签：**许可**与**引擎参数**。本篇覆盖许可状态的读取、许可的更新，以及引擎参数的查看。

## 1. 查看产品许可状态

**前置条件**
* 已进入组织模块，并在左侧导航选择「系统」。页面默认停在「许可」标签。

**操作步骤**
1. 读取「产品许可」卡片右上角的状态标记：有效、即将到期、已过期或不限期。
2. 核对卡片内的行：许可名称、到期时间、剩余天数。
3. 关注卡片底部的提示：即将到期时提示剩余天数并建议提前续期；已到期时提示部分功能可能无法使用。

**预期结果**
* 不限期许可的剩余天数显示为「不限期」。
* 到期时间按当前语言的日期格式显示。

## 2. 更新产品许可

**前置条件**
* 已从厂商处获得新的许可证内容。

**操作步骤**
1. 在「产品许可」卡片右上角点击「更新许可」。
2. 把厂商提供的许可证内容粘贴到文本框中。
3. 点击「确认更新」。

**预期结果**
* 校验通过时提示「许可已更新」，卡片刷新为新的状态与到期时间。
* 校验不通过时不会生效，原因显示在弹窗内，可修正内容后重试。

:::danger[更新会立即生效且不可回退]
新许可会立即替换整台引擎当前的产品许可，旧许可无法恢复。请确认拿到的是正确内容再提交。
:::

## 3. 查看引擎参数

**操作步骤**
1. 在系统页切换到「引擎参数」标签。
2. 参数按三组展示：**流程引擎**、**引擎与运行时**、**作业执行器**。
3. 点击分组或字段行可展开、收起；较长的值展开后可再次收起。

**预期结果**
* 可读到引擎名称、版本、历史级别、数据库、运行环境、作业执行器线程池与队列等运行参数。
* 这些参数为只读展示，用于排查问题与核对环境，不能在本页修改。

## 4. 刷新读数

**操作步骤**
1. 点击页面右上角的刷新按钮。

**预期结果**
* 许可与引擎参数重新读取；读取失败时给出重试入口。
