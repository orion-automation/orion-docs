授权记录回答一个问题：**谁**（身份）能对**哪类资源**（资源类型）做什么（权限）。本篇覆盖授权记录的增、查、改、删。

## 1. 创建授权记录

**前置条件**
* 已进入组织模块，并在左侧导航选择「授权」。
* 目标用户或用户组已存在；若尚未创建，请先按 [如何管理组织用户](/howto/admin/user/) 与 [如何管理用户组与成员](/howto/admin/group/) 建好。

**操作步骤**
1. 点击列表右上角的「创建授权记录」，右侧滑出维护抽屉。
2. 选择 **资源类型**：它决定后续可选的权限范围（如应用、流程定义、流程实例、任务、租户等）。
3. 选择 **类型**：授予、撤销或全局。
   * 选「全局」时身份固定为「所有人」，不能指向某个用户或组——这是引擎对全局授权的约束。
4. 填写 **身份**：先选用户或组，再填其 ID。
5. 填写 **资源 ID**：
   * `*` 表示该类型的全部实例；
   * 要限定到某一个对象（某条流程定义、某个用户……）就填它的 ID；
   * 系统类资源的资源 ID 由引擎固定为 `*`；
   * 应用类资源的资源 ID 是模块名，如 `design`、`run`、`task`。
6. 勾选需要的 **权限**；可用「全选」「全不选」快速操作，右侧计数显示已选与总数。
7. 点击「创建」提交。

**预期结果**
* 提示「授权记录已创建」，列表出现新记录。
* 同一个「类型 + 身份 + 资源」只允许一条：若引擎里已有同样的记录，创建会被拒绝并提示已有记录的引用。

:::caution[改动身份等于换主体]
修改已有记录的身份，等于把这项授权换一个主体——原来那个用户或组会立刻失去它。
:::

## 2. 筛选与排序授权记录

**操作步骤**
1. 点击列表右上角的「筛选」。
2. 按需填写：资源类型、资源 ID、授权类型、用户 ID 列表、组 ID 列表、授权 ID。
3. 点击「重置」清空条件；点击列头可按该列排序。

**预期结果**
* 列表只显示符合条件的记录；修改条件后列表自动刷新。
* 身份列显示为「所有人」「用户 · `{ID}`」或「组 · `{ID}`」；资源 ID 为 `*` 时显示「全部实例」；没有勾选任何权限时权限列显示「（无）」。
* 未收录的资源类型编号按原样显示。

## 3. 修改授权记录

**操作步骤**
1. 点击列表中的目标记录，右侧滑出维护抽屉。
2. 资源类型与授权类型在此不可改，其余字段（身份、资源 ID、权限）按需调整。
3. 点击「保存」提交。

**预期结果**
* 提示「授权记录已更新」。
* 若记录在引擎里存的是「全部权限」或「无权限」，抽屉会以标记提示，保存时照原样写回。

## 4. 删除授权记录

**操作步骤**
1. 在列表中点击目标记录行的删除按钮。
2. 在确认框中确认。

**预期结果**
* 提示「授权记录已删除」，列表移除该行。被删除的主体不再获得这项授权。
