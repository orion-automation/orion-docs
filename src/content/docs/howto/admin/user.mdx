用户面板维护组织内的账号、姓名与联系方式。本篇覆盖账号的增、查、改、删与批量导入。

## 1. 新建单个用户

**前置条件**
* 已进入组织模块，并在左侧导航选择「用户」。

**操作步骤**
1. 点击列表右上角的「新建用户」。
2. 填写 **用户 ID**：它是登录用的标识，创建后不能修改，且必须唯一；对话框会实时检查是否已被占用。
3. 按需填写 **名**、**姓**、**邮箱**——三项不能同时为空，单个可以留空。
4. 设置 **初始密码**：至少 6 位，可用数字、英文字母和特殊符号，不能含空格或中文。
5. 点击「新建用户」提交。

**预期结果**
* 对话框切换为账号信息页，显示用户 ID、初始密码、姓名与邮箱。
* 点击「复制账号信息」可一次性复制；点击「完成」关闭。

:::danger[初始密码只在此刻可见]
密码不会被界面保存，关闭对话框后无法再取回。请立即转告本人。
:::

## 2. 批量导入用户

**前置条件**
* 已准备好 Excel 文件（`.xlsx` 或 `.xlsm`；老格式 `.xls` 请先另存为 `.xlsx`）。
* 单次不超过 100 行，超出请拆成多份。

**操作步骤**
1. 点击列表右上角的「导入」。
2. 没有现成表格时，先点击「下载模板」，按模板填写。
3. 表头需包含五列（顺序不限，多余的列会被忽略）：**用户 ID、初始密码、姓、名、邮箱**。其中只有邮箱可以留空。
4. 点击「选择 Excel 文件」，核对预览中的校验结果：有问题的行会被标出原因。
5. 点击「导入 N 个用户」开始创建。

**预期结果**
* 逐个创建期间显示进度，完成后报告成功、失败与跳过的行数；有问题的行被跳过，其余照常创建。
* 结算页提供「复制全部」与「下载账号表」，请立即保存初始密码——关闭窗口后就再也拿不回来了。
* 需要补录时点击「再导一批」，完成后点击「完成」。

:::caution[导入过程中不要关闭窗口]
引擎没有批量接口，只能逐个创建，中途关闭会留下已建成的用户。
:::

## 3. 查看与编辑用户详情

**操作步骤**
1. 点击列表中的任意一行，右侧滑出「用户详情」。
2. 在「用户信息」页修改名、姓、邮箱，点击「保存」。
3. 切换「所在组」「所在租户」页签，查看该用户直接加入的组与租户（不含由所属组继承来的）。
4. 切换「所拥有权限」页签，查看直接授予该用户的应用级授权；经所属组继承的、全局的授权不在此列。

**预期结果**
* 名、姓、邮箱不能同时为空，单个可以留空。
* 保存成功后提示「`{用户 ID}` 的资料已更新」。

## 4. 解锁、改密与删除用户

**前置条件**
* 执行改密需要提供你自己的密码（当前登录用户的密码），不是该用户的旧密码。

**操作步骤**
1. 在列表中点击目标行右侧的「更多操作」菜单。
2. 按需选择：
   * **解锁用户**：清除该用户因多次登录失败而被锁定的状态；密码与资料不会改变。若该用户本来就没被锁，这一步不会产生任何变化。
   * **更新用户密码**：填写新密码与确认新密码，再填写你自己的密码以确认这次修改。
   * **删除用户**：在确认框中确认后永久删除，无法撤销，该用户的组成员关系会一并移除。

**预期结果**
* 操作成功后列表刷新，并提示对应的完成信息。
* 若提示身份服务只读，说明本部署不允许修改用户、组与成员关系，请让运维检查引擎配置。

## 5. 筛选与排序用户

**操作步骤**
1. 点击列表右上角的「筛选」，在面板中按需填写：用户 ID 列表、名包含、姓包含、邮箱包含、所属组、所属租户。
2. 需要忽略大小写时勾选对应选项；点击「重置」清空全部条件。
3. 点击列头可按该列排序；修改筛选条件后列表自动刷新。

**预期结果**
* 列表只显示符合条件的用户；筛选按钮上会标出当前生效的条件数。
