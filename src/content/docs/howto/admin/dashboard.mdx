组织模块是管理员维护账号、权限与租户的工作台。本篇覆盖进入方式、看板读数与面板导航。

## 1. 进入组织模块

**前置条件**
* 已登录 ORION。
* 账号属于组织管理员组（`orionadmin`）。公开版中，其他账号打开本模块会看到「无权访问」提示。

**操作步骤**
1. 点击顶部栏左侧的「打开应用菜单」按钮。
2. 在展开的导航抽屉中点击「组织」。
3. 面包屑显示「组织 > 看板」，页面默认停在看板。

**预期结果**
* 左侧出现可折叠的导航栏，依次为看板、用户、组、租户、授权、系统。
* 拖拽导航栏右边缘可调宽，双击可收拢或展开。

## 2. 读取平台状态

**操作步骤**
1. 在看板的「平台状态」卡片中，自上而下核对以下读数。
2. 关注带异常提示的条目：流程引擎显示离线时，提示「无法连接引擎，请检查服务」；读数被拒绝时，提示检查账号权限。

**预期结果**
* **流程引擎**：在线或离线，附引擎版本。
* **数据库**：数据库类型与版本。
* **运行环境**：引擎所用的运行环境版本。
* **作业执行器**：已启用或已停用，附线程池与队列配置。停用后异步任务与定时器都不会执行。
* **历史级别**：已关闭、仅活动、审计或完整，分别对应无审计记录、仅实例流转、含任务与决策、含变量变更。
* **产品许可**：有效、即将到期、已过期或不限期，附到期时间与剩余天数。

:::caution[作业执行器被停用时]
异步任务与定时器都不会执行，已部署的流程会停在等待节点。若非有意停用，请检查引擎服务。
:::

## 3. 查看组织规模并跳转管理

**操作步骤**
1. 在看板的「组织规模」卡片中，读取用户、组、租户、授权四个计数。
2. 点击任一计数卡片，直接跳转到对应管理面板。

**预期结果**
* 卡片下方提示「点击管理用户」等文案，点击后进入对应列表页。
* 返回看板可再次点击左侧导航的「看板」。

## 4. 刷新看板读数

**操作步骤**
1. 点击看板标题右侧的刷新按钮。

**预期结果**
* 平台状态与组织规模重新读取，按钮在读取过程中显示旋转状态。
