用户组按职责划分成员，统一分配权限。本篇覆盖组的创建、成员维护与删除。

## 1. 新建用户组

**前置条件**
* 已进入组织模块，并在左侧导航选择「组」。

**操作步骤**
1. 点击列表右上角的「新建用户组」。
2. 填写 **组 ID**：创建后不能修改，且必须唯一；对话框会实时检查是否已被占用。
3. 按需填写 **名称** 与 **类型**——两者都可以不填，类型是自由文本（如 `Organizational Unit`）。
4. 点击「新建用户组」提交。

**预期结果**
* 列表出现新组，提示「用户组 `{组 ID}` 已创建」。

## 2. 批量导入用户组

**前置条件**
* 已准备好 Excel 文件（`.xlsx` 或 `.xlsm`；`.xls` 请先另存为 `.xlsx`）。

**操作步骤**
1. 点击列表右上角的「导入」。
2. 没有现成表格时，先点击「下载模板」。
3. 表头需包含：**组 ID**（必填）、**名称**（可选）、**类型**（可选）。
4. 选择文件并核对校验结果，点击「导入 N 个」开始创建。

**预期结果**
* 校验规则与新建一致：组 ID 不能为空、只能包含字母、数字与 `_ @ . -` 且不能以 `-` 开头、不能与已有组重复。
* 有问题的行被跳过，其余照常创建；完成后报告成功、失败与跳过的行数。

## 3. 添加与移出组成员

**前置条件**
* 目标用户已存在；若尚未创建，请先按 [如何管理组织用户](/howto/admin/user/) 建好。

**操作步骤**
1. 点击列表中的目标组，右侧滑出「用户组详情」，切换到「用户」页签。
2. 点击「添加用户」，输入 ID 或名称查找（名称匹配区分大小写），可多选。
3. 点击「加入（N）」确认。
4. 需要移出时，点击该成员行的「移出」，在确认框中确认。

**预期结果**
* 加入后提示「已将 `{用户}` 添加进本用户组」；移出后提示「已把「`{用户}`」从本用户组移出」。
* 被移出的组本身不会被删除，也不影响其他成员；需要时可重新加入。

### 批量导入成员

**操作步骤**
1. 在「用户」页签点击「导入用户」。
2. 没有表格时先「下载模板」；表头只需一列：**用户 ID**（填 ID，不是邮箱）。
3. 选择文件后点击「导入 N 个」。

**预期结果**
* 这里只建立归属关系，不会新建用户；用户必须已经存在。
* 找不到的用户被跳过，对话框给出清单，可「复制清单」或「下载清单」，去用户列表建好后再回来导一次。

## 4. 查看组的所属租户与权限

**操作步骤**
1. 在「用户组详情」中切换「所属租户」页签，查看该组直接所属的租户。
2. 切换「权限」页签，查看直接授予该组的授权记录。

**预期结果**
* 组成员会按优先级继承这些权限，但它不等于某个成员实际能做什么——成员自己名下的授权、以及全局授权都会叠加进来。
* 在「所属租户」页签可添加或移出租户，操作方式与成员管理一致。

## 5. 删除用户组

**前置条件**
* 删除前建议先确认组内成员已迁出，或确认这些成员不再需要该组的权限。

**操作步骤**
1. 在列表中点击目标组行右侧的「更多操作」菜单。
2. 选择「删除用户组」，在确认框中确认。

**预期结果**
* 提示「用户组 `{组 ID}` 已删除」，列表移除该行。若提示该组已不存在，刷新列表即可。
