在工作空间列表点击任一工作空间即进入详情页。详情页由**总览卡片**与三个页签（业务应用 / 资源 / 测试运行）组成，README 与协作人从这里维护。本篇按页签给出使用大纲，细节后续补充。

## 1. 读取总览指标

**操作步骤**
1. 进入工作空间详情，先看顶部的四张总览卡片。
2. 依次核对：**业务应用**（已部署 / 草稿两组计数）、**资源**（资源总数）、**测试运行**（进行中 / 已完成）、**README**。

**预期结果**
* 业务应用卡按**最新快照状态**分组：最新快照已部署计入「已部署」，其余计入「草稿」。
* 测试运行卡的两个数字来自引擎实时统计；点「在新标签页查看这些流程的实例」会直接打开运行模块中该工作空间全部流程的实例列表。
* README 卡为空时引导撰写，点「完整阅读」打开 README 抽屉。

## 2. 业务应用页签

**前置条件**
* 详情页处于「业务应用」页签（默认页签，页签胶囊上带应用数量）。

**操作步骤**
1. 点击「创建业务应用」，填写应用**名称**（必填）与**描述**（可选），确认创建。
2. 对已有应用，点卡片上的操作菜单按需执行：**重命名**、**导出应用**、**删除**。
3. 需要按名称定位时用页签内的搜索框过滤。

**预期结果**
* 创建对话框说明「应用将包含以下结构，设计、开发资源将有组织地放置于这些目录中」，并列出**发现 / 设计 / 测试运行**三个阶段；创建后应用卡片出现在列表中。
* 导出应用下载一份该应用的 `app.json` 描述文件（含应用与其资源、快照的清单信息）。
* 删除前弹出确认 `确定删除业务应用「{name}」吗？`，确认后卡片移除。
* 搜索无匹配时显示「未找到匹配的业务应用」。
* 点击卡片进入应用详情，按发现 / 设计 / 运行三段管理资源（见[如何管理业务应用与资源](/howto/build/app/)）。

:::note[导入应用尚未接入]
操作菜单中的「导入应用」当前只做文件选择，选中后会提示「已选择「`{name}`」；导入功能尚未接入。」——暂不能用来还原应用。
:::

## 3. 资源页签

**前置条件**
* 切到「资源」页签（页签胶囊显示资源数量；有搜索词时显示命中数）。

**操作步骤**
1. 用搜索框按资源或业务应用名称过滤。
2. 需要按 BPMN 流程内容检索时，打开**全文检索**开关，再输入关键词。
3. 需要换看法时，用右上「资源视图」在**列表**与**业务架构**之间切换。
4. 点「导出列表」把当前视图筛选后的列表导出为 CSV。

**预期结果**
* 全文检索状态依次提示「正在建立索引 `{done}`/`{total}`」→「已索引 `{n}` 份 BPMN 流程」；有读取失败时另计「`{n}` 份读取失败」，命中时显示「`{n}` 处匹配」。
* 工作空间里没有 BPMN 流程时，全文检索给出「这个工作空间没有可检索的 BPMN 流程」，属于正常空态。
* **业务架构**视图按业务域 → 流程组 → 流程三级分组、只列 BPMN 流程，父行可折叠；没有 BPMN 时提示「这个工作空间还没有 BPMN 流程」。
* 导出的 CSV 反映**当前筛选结果**，不是全量。

## 4. 测试运行页签

**前置条件**
* 引擎可达（页面数字与行点击跳转都依赖引擎中的历史实例数据）。

**操作步骤**
1. 切到「测试运行」页签。
2. 按业务应用分组逐行核对：**资源**、**流程定义 Key**、**进行中**、**已完成**，组尾有小计。
3. 需要下钻时点击某一行。

**预期结果**
* 每行数字按该 BPMN 资源解析出的流程定义 Key 向引擎实时计数。
* 点击行在**新标签页**打开运行模块的实例列表，查询条件已带上该行的流程定义 Key。
* 工作空间里还没有 BPMN 资源时显示空态「这个工作空间里还没有流程（BPMN）资源。」；清单拉取失败时给出提示与「重试」。

## 5. 维护 README

**操作步骤**
1. 打开 README 抽屉（总览卡「完整阅读」或页内入口），点**编辑**。
2. 用 Markdown 撰写工作空间说明——应用背景、环境依赖或版本契约。
3. 写完点保存；放弃修改前离开会提示「README 还有未保存的修改，确定放弃吗？」。

**预期结果**
* 编辑位有**返回预览**切换；占位提示「在这里撰写工作空间说明（支持 Markdown）…」。
* README 内容随工作空间保存；抽屉空态提示「暂无 README 内容，点击右上角「编辑」开始撰写。」
* 加载失败时提示「README 加载失败，请检查网络或稍后重试。」

## 6. 管理协作人

**操作步骤**
1. 点「管理协作人」，在搜索框输入姓名或邮箱查找人员并添加。
2. 对已加入的协作人可调整角色或移出。

**预期结果**
* 角色共四档：**负责人 / 管理者 / 编辑者 / 评论员**。
* 搜索无结果时提示「没有找到匹配的人员」；匹配到的人都已在工作空间内时提示「匹配到的人都已经在这个工作空间里了，继续输入可缩小范围」。
* 增删改角色失败分别提示「添加协作人失败，请稍后重试」「移出协作人失败，请稍后重试」「修改角色失败，请稍后重试」，可重试。
