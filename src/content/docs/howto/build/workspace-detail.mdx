在工作空间列表点击任一工作空间即进入详情页。详情页由**总览卡片**与三个页签（业务应用 / 资源 / 测试运行）组成，README 与协作人从这里维护。各页签的用法拆在独立篇目里：

* 业务应用页签：[如何管理工作空间业务应用](/howto/build/workspace-apps/)
* 资源页签：[如何浏览工作空间资源](/howto/build/workspace-resources/)
* 测试运行页签：[如何查看工作空间测试运行](/howto/build/workspace-runs/)
* README 与协作人：[如何维护 README 与协作人](/howto/build/workspace-readme/)

## 1. 读取总览指标

**前置条件**
* 已登录 ORION，进入目标工作空间的详情页。

**操作步骤**
1. 进入工作空间详情，先看顶部的四张总览卡片。
2. 依次核对：**业务应用**（已部署 / 草稿两组计数）、**资源**（资源总数）、**测试运行**（进行中 / 已完成）、**README**。

**预期结果**
* 业务应用卡按**最新快照状态**分组：最新快照已部署计入「已部署」，其余计入「草稿」。
* 测试运行卡的两个数字来自引擎实时统计；点「在新标签页查看这些流程的实例」会直接打开运行模块中该工作空间全部流程的实例列表。
* README 卡为空时引导撰写，点「完整阅读」打开 README 抽屉。
