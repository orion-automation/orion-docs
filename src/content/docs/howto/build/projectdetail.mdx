本指南指导您在设计模块（协同组详情页）中完成核心业务资产的管理、检索、迁移，以及团队成员权限与项目说明的配置。

## 1. 资源资产管理

### 1.1 如何添加新的业务流程或其他资源资产

**前提条件：** 已进入目标应用的协作详情页，并拥有“管理员”或“编辑者”权限。

1. 在页面右上角功能区，点击 **`+ 添加`** 按钮。
2. 在弹出的资源类型选择框中，选择目标类型（例如：**业务流程**、**业务规则**、**技能** 或 **交互表单**）。
3. 输入资源名称（建议遵循企业命名规范）。
   :::note
   为保障企业自动化任务的确定性流转，业务流程资产需严格符合 BPMN 2.0
 规范与 ORION 引擎的执行约定。
   :::
4. 确认创建后，系统将在“资源列表”中生成对应的 `bpmn`、`dmn`、`skill` 或 `form` 条目。
5. 点击该条目右侧的 **`⋮` (操作)** 图标，进入建模器画布进行深度编排与规则契约设定。

### 1.2 如何快速检索并管理特定类型的资源

1. 在页面中部的资源分类看板中，点击对应的资源卡片（如 **业务流程 Process**），下方的资源列表将自动过滤并仅显示该类资产。
2. 若需精确查找，点击右上角的 **`查询`** 按钮，输入资源名称进行模糊匹配。
3. 核对列表中对应资产的**创建人**与**最后更新日期**，以确认当前版本状态。
4. 点击目标资源右侧的 **`⋮` (操作)** 菜单，执行重命名、删除或进入编排界面等后续动作。

### 1.3 如何通过排序快速审阅资产列表

1. 确保当前处于 **`资源`** 选项卡下。
2. 在资源列表表头中，点击 **`资源类型`** 右侧的排序图标（`↕`）。
3. 列表将根据资源类型（如 `bpmn`、`form`）或首字母顺序自动重排。
4. 结合更新时间字段，快速定位并审查历史资产或批量核对特定类型的规则配置。

### 1.4 如何通过迁移导入或导出项目资源

**前提条件：** 若执行导出操作，建议确认当前列表中的核心资产均已保存至最新状态；若执行导入操作，需准备好标准格式的资源 ZIP 包。

1. 点击页面右上角的 **`迁移`** 按钮。
2. 根据弹窗指引，选择需要执行的迁移操作：
   * **导出资源：** 将当前项目下所有的资源资产打包下载为 ZIP 压缩文件。
   * **导入资源：** 上传并解析从其他项目导出的资源 ZIP 文件，将其批量导入至当前项目空间。
3. 确认执行后，系统将自动完成资源的打包下载或解析导入。
4. 若为导入操作，可在左侧导航栏的 **`资源`** 选项卡刷新页面，确认新资产已成功加载到资源列表中。

## 2. 团队协作与项目说明

### 2.1 如何邀请协作成员并分配项目权限

**前提条件：** 需具备当前项目的**管理员**权限。

1. 在页面左侧导航栏，点击 **`协作成员`** 选项卡进入团队管理界面。
2. 点击邀请操作区域，输入待邀请用户的账号信息以将其加入当前项目。
3. 根据团队契约，为受邀用户设定对应的角色权限：
   * **管理员：** 拥有当前项目的所有配置、资源分配与人员调度权限。
   * **编辑者：** 支持对业务流程、交互表单等核心资产进行编排与修改。
   * **评论员：** 仅拥有资源与设定的只读浏览权限，无任何编辑或修改权限。
4. 确认发出邀请，受邀用户将在工作台中收到加入通知。

### 2.2 如何查阅及编写项目说明文档

1. 在页面左侧导航栏，点击 **`说明文档`** 选项卡。
2. 进入编辑模式，使用 **Markdown** 语法录入当前应用的核心业务说明、环境依赖或版本契约信息。
3. 完成编写并提交，系统将自动渲染并保存文档结构。
4. 具有访问权限的团队成员点击该选项卡即可实时查阅标准化的说明信息。
