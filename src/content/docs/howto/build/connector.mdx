**前置条件**
* 已在「连接器」分类创建组件并点击组件行进入详情页。

**操作步骤**
1. 详情页顶部页签：**基本信息**、**参数**、**请求头**、**请求体**、**响应**、**调用计划**。
2. **基本信息**页签填组件名称、说明、标签、版本标签——这些是组件记录字段，不属于接口配置。
3. **详细设置**里逐项配置：
   * **方法**与**接口地址**——地址引用流程变量写 `${orderId}`，变量名在下方表格把该行「来源」设为「流程变量」；
   * **请求头模板**、**查询参数模板**——每行是「名字 + 值 + 来源（常量或流程变量）」；
   * **路径参数**——由接口地址中的 `${名字}` 占位符自动生成，无需手动新增；
   * **请求体字段**——按字段录入会合并为一个 JSON 对象；要精确控制类型请用**请求体模板**；
   * **状态码存入变量**——把实际返回的状态码存进该流程变量（如 200 / 404），留空不写回；
   * **响应体字段**——声明「响应字段 → 流程变量」的映射，响应字段填 JSON 路径（如 `data.orderId`，填 `statusCode` 则取 HTTP 状态码），未声明映射时仍可获取完整响应体。
4. 保存前可在**调用计划**页签核对这份配置被流程设计引用时编译出的形状（只读）。

**预期结果**
* **参数**页签的实时预览显示「这份配置运行时发出去的请求」：方法、编译后的地址与各参数条数。
* **在流程设计中**：
  1. 先把连接器放进业务应用——连接器目录「更多操作 → 从AI 能力中心导入」，或在应用内新建；
  2. 画布上选中服务任务 → 属性面板「常规」分组的**快速设置**下拉选中它，一次写入整条实现；或在「添加元素」面板的**连接器**页签点击，画布直接落一枚已绑定该连接器的服务任务（任务名自动取组件名）。
