**前置条件**
* 已在「模型」分类创建接入并进入详情页。

**操作步骤**
1. 详情页顶部页签：**基本信息**、**接入参数**（页签上显示「必填项已填 `{filled}` / `{total}`」）。
2. **接入参数**逐项填写：
   * **供应商**——自由文本，例如 官方服务 / 私有化部署；
   * **模型**列表——一个接入可挂多个模型，点**添加模型**；**模型名**必填且不能重复（流程按模型名引用），显示名可选；
   * **接入地址（Base URL）**——兼容 OpenAI 协议的服务填到 `/v1` 为止，不要带 `/chat/completions`；
   * **API 密钥**——粘贴服务方签发的密钥，明文保存在这条记录的配置里；
   * **温度**、**单次最大输出**、**上下文窗口**（模型一次能读入的 token 数，不出现在请求里）；
   * **推理强度**——关闭思考 / 低 / 中 / 高 / 最高，档位越高思考越久，不指定则不发送；开启后温度将被忽略；
   * **协议风格**——OpenAI 兼容 / Anthropic Claude / Google Gemini / Azure OpenAI / 自定义内网网关（内网网关一般选「OpenAI 兼容」）；**对话路径**留空则按协议风格自动推导；**API 版本**填在路径查询串里而非请求头；**超时（毫秒）**与 ORION 侧任务超时对齐，避免流程实例被长期占住；
   * **高级设置**——**额外请求头**（JSON 对象文本，网关 / WAF 要求的自定义头写这里）、**额外请求体字段**（并入每次请求体）、**能力声明**（对话 / 视觉 / 工具调用 / JSON 模式，用于流程编排按能力筛模型；不勾选只代表「未声明」）。
3. 用顶栏**测试**按钮选一个模型实发一次请求，验证配置能否调通。

**预期结果**
* **在流程设计中**：模型不直接上画布——智能体与智能文档处理的**模型**页签点**导入模型**引用它；流程节点按**模型名**引用模型，所以模型名不能重复。
