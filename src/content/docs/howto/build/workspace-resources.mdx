**前置条件**
* 切到「资源」页签（页签胶囊显示资源数量；有搜索词时显示命中数）。

**操作步骤**
1. 用搜索框按资源或业务应用名称过滤。
2. 需要按 BPMN 流程内容检索时，打开**全文检索**开关，再输入关键词。
3. 需要换看法时，用右上「资源视图」在**列表**与**业务架构**之间切换。
4. 点「导出列表」把当前视图筛选后的列表导出为 CSV。

**预期结果**
* 全文检索状态依次提示「正在建立索引 `{done}`/`{total}`」→「已索引 `{n}` 份 BPMN 流程」；有读取失败时另计「`{n}` 份读取失败」，命中时显示「`{n}` 处匹配」。
* 工作空间里没有 BPMN 流程时，全文检索给出「这个工作空间没有可检索的 BPMN 流程」，属于正常空态。
* **业务架构**视图按业务域 → 流程组 → 流程三级分组、只列 BPMN 流程，父行可折叠；没有 BPMN 时提示「这个工作空间还没有 BPMN 流程」。
* 导出的 CSV 反映**当前筛选结果**，不是全量。
