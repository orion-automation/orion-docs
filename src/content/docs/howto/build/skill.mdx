**前置条件**
* 已在「技能」分类创建技能并进入详情页。

**操作步骤**
1. 详情页顶部页签：**基本信息**、**触发规则**、**编排**、**调用计划**。
2. **基本信息**核对**技能定义 Key**——它自动取自编排页签的流程 ID，这里不能直接修改；两处是同一个值，在**编排**页签的画布上改流程 ID 即可（未起名时点**去编排页签起名**）。
3. **触发规则**页签三段各写若干行（一行一条）：
   * **适用场景**——什么情况下该用这个技能，例如「员工入职办理」「采购申请审批」；
   * **禁止场景**——什么情况下不该用；若应交给别的技能处理，写明交给哪一个；
   * **约束规则**——使用时必须遵守的规定，例如「金额超过 10 万元需二级审批」。
4. **参数契约**两表：**入参契约**（调用时交给流程的变量）与**结果契约**（技能返回的变量），左边是技能对外声明的字段名，右边是背后流程里接收 / 产出它的变量名，留空即与字段名同名。
5. **编排**页签设计技能自己的流程；**调用计划**页签只读查看它被编排器引用时编译出的形状。

**预期结果**
* **在流程设计中**：技能经由智能体被流程调用——在智能体详情的**技能**页签点**添加**，搜索技能名称、定义 Key 或描述后选入；流程侧按**技能定义 Key** 引用它。
