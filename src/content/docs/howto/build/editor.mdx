在业务应用中点击资源即可进入编辑器。本篇覆盖编辑器的日常操作：保存、版本、视图、导入导出、模拟与分享。

## 1. 保存当前编辑

**前置条件**
* 已在业务应用中打开一个流程或决策资源。

**操作步骤**
1. 在画布上完成编辑。
2. 点击工具条上的**保存**，或按 `⌘/Ctrl + S`。

**预期结果**
* 按钮短暂显示「保存中…」，完成后内容写回当前资源。
* 保存前的内容不会丢失；下次打开该资源时看到的就是最近一次保存的结果。

## 2. 另存为新版本

**适用场景**：想保留当前版本的快照，又继续在新的一版上改。

**操作步骤**
1. 点击工具条上的**另存为**。
2. 填写**版本名称**（必填，例如 `v2 优化前`）。
3. 点击**创建**。

**预期结果**
* 为当前资源新建一条版本记录，**原来的版本保留**；之后的保存会写到这一新版本。
* 版本名称为空时提示「请填写版本名称」。
* 另存为只对已保存到服务端的资源可用；仅存在本机的草稿与素材没有「版本」概念。

## 3. 撤销、重做与视图调整

**操作步骤**
1. 误操作时点**撤销**，反悔撤销时点**重做**。
2. 需要调整画布视野时，用工具条上的**缩小** / **放大**。
3. 更多视图选项在**更多操作**菜单里：**适应窗口**、**全屏编辑** / **退出全屏编辑**、**显示迷你地图** / **隐藏迷你地图**。

**预期结果**
* 撤销历史按操作步进回退；重做在没有新的编辑前可逐步恢复。
* 全屏编辑隐藏外围界面，退出后恢复原布局。

## 4. 导入与导出

**操作步骤**
1. **导入**：点**更多操作** → **导入 BPMN 文件**，选择本地文件。
2. **导出**：点工具条上的**导出**，在 PNG、SVG、BPMN 三种格式中选择。

**预期结果**
* 导入会**覆盖当前编辑内容且尚未保存**，成功提示形如「已导入 `{name}`，覆盖了当前编辑内容（尚未保存）」；不是有效 XML 时提示「这个文件不是有效的 XML，无法解析」，空文件提示「文件是空的，没有内容可以导入」。导入后记得保存。
* 导出按所选格式下载当前画布内容。

## 5. 运行本地模拟

**操作步骤**
1. 点击工具条上的**模拟**进入模拟模式。
2. 用**播放模拟** / **暂停模拟**推进令牌，**重置模拟**回到起点，**流程模拟日志**查看逐步记录。
3. 需要走表单时，点**模拟表单面板**打开右侧表单区，按提示**启动流程**、**提交并继续**。

**预期结果**
* 模拟完全在本地画布上推进令牌，**不会在引擎上启动真实流程实例**。
* 节点没有绑定表单时直接提交即可继续；已绑定表单但读不到内容时给出提示并可**重新读取**；没有待处理节点时提示「当前没有等待处理的节点。」

:::note[模拟与测试运行的区别]
模拟是画布上的本地推演，用于走查设计；引擎上的真实实例统计在工作空间详情的「测试运行」页签与运行模块中查看。
:::

## 6. 打开编辑器面板

**更多操作**菜单中还收纳了这些面板：

* **业务架构**——按阶段查看流程的架构视图；
* **责任登记**——登记流程各环节的责任人；
* **XML 代码视图**——直接查看与编辑底层 XML；
* **元素矩阵** / **标记清单**——盘点画布上的元素与标记；
* **设计校验**——检查画布上的设计问题；
* **属性面板**——调整选中元素的属性。

工具条上的**流程文档**按钮打开该流程的文档面板。

## 7. 生成只读分享链接

**操作步骤**
1. 点击工具条上的**分享**。
2. （可选）设置**分享密码**：4-32 位字母、数字或符号；留空则不设密码。
3. 点击**生成分享链接**，再点复制。

**预期结果**
* 生成后显示「分享链接已生成（凭链接即可访问）」或「分享链接已生成（需输入密码访问）」。
* 未设密码时提示「未设置密码，任何人凭此链接均可只读查看。」；设了密码时对方打开链接需输入访问密码才能只读查看。
* 密码规则不满足时提示「密码需为 4-32 位字母、数字或符号（留空则不设密码）」；复制失败提示「复制失败，请手动复制」。
