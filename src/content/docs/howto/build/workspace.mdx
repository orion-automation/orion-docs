设计模块的第一层是**工作空间**：一个工作空间容纳团队的业务应用与全部设计资源。本篇覆盖工作空间的创建、查找与生命周期操作。

## 1. 创建工作空间

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「设计」。
* 页面停留在左侧导航的「工作空间」面板（进入设计模块后的默认落点）。

**操作步骤**
1. 点击「创建工作空间」按钮。
2. 填写 **工作空间名称**（必填）。
3. 填写 **初始业务应用名称**（必填；默认值为「业务流程应用」，建议按业务域命名，例如「销售订单处理」）。
4. 点击「创建」提交。

**预期结果**
* 创建成功后关闭对话框，列表自动切到「我的工作空间」页签并刷新，新工作空间出现在列表中。
* 系统在该工作空间下**自动创建步骤 3 指定的业务应用**——后续的流程、决策、表单与连接器资源都挂在业务应用下。
* 名称校验不通过或接口失败时对话框保持打开并显示错误信息，修正后可直接重试。

:::note[一个工作空间只初始化一个应用]
创建对话框只要求「名称 + 初始业务应用名称」两件事；后续可以在工作空间详情里随时再建新的业务应用，也可以把资源分散到多个应用中管理。
:::

## 2. 切换页签与查找工作空间

**前置条件**
* 账户内至少存在一个工作空间（自己创建或被邀请加入）。

**操作步骤**
1. 在列表顶部的两个页签间切换：**我的工作空间**（我创建的）与**我参与的工作空间**（受邀加入的）。
2. 需要精确定位时，用搜索框按名称过滤。

**预期结果**
* 页签切换后列表只显示对应归属的工作空间。
* 搜索框输入名称后列表实时收窄；无匹配时显示空态「未找到匹配的工作空间」。

## 3. 重命名与归档

**前置条件**
* 目标工作空间在列表中可见。

**操作步骤**
1. 在目标行最右侧点「操作」菜单。
2. 按需执行：
   * **重命名**：在提示中输入新的工作空间名称并确认。
   * **归档**：阅读二次确认文案后确认。

**预期结果**
* 重命名后列表立即刷新显示新名称；失败时提示「重命名失败，请稍后重试」。
* 归档执行中显示「归档中…」，完成后该工作空间从列表移除；失败时提示「归档失败，请稍后重试」。

:::danger[归档不可撤销]
归档确认文案写明：`「{name}」将从工作空间列表中移除，此操作无法撤销。`执行前确认该工作空间不再需要。
:::
