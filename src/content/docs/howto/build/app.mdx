业务应用是资源的容器：流程、决策、表单、连接器、业务对象都挂在应用的文件树下。本篇覆盖从进入应用到新建资源、再到查看已部署流程的路径。

## 1. 进入业务应用

**前置条件**
* 已登录 ORION，进入目标工作空间的详情页。

**操作步骤**
1. 在「业务应用」页签中找到目标应用卡片。
2. 点击卡片进入应用详情。

**预期结果**
* 页面进入应用详情，左侧显示文件树，右侧是内容区（未打开文件时显示引导）。
* 未打开任何文件时，右侧显示「选择一个文件开始」，提示在左侧选择发现或设计段下的文件，或查看运行段的已部署流程。

## 2. 认识左侧文件树

文件树分三段：

* **发现**：关键发现、原始素材——梳理阶段沉淀的文档与素材。
* **设计**：编排、决策、UX、连接器、业务对象——五类设计资源的固定目录。
* **运行**：引擎上已部署的流程定义清单（见[第 5 节](#5-查看已部署的流程定义)）。

文件树优先展示服务端已保存的资源；资源清单尚未加载完成时会先显示本地示例内容，加载成功后自动替换。

## 3. 新建资源

**前置条件**
* 已进入目标应用，左侧文件树已加载。

**操作步骤**
1. 将鼠标悬停在目标目录行上，点击行尾的「更多操作」。
2. 在菜单中选择该目录的新建入口：

| 目录 | 新建入口 |
|---|---|
| 关键发现 | 新建文档 |
| 编排 | 新建流程 |
| 决策 | 新建决策 |
| UX | 新建表单 |
| 连接器 | 新建 JS Worker、新建 HTTP 接口 |
| 业务对象 | 新建业务对象 |

3. 在对话框中填写**名称**（必填）。
4. 需要时修改**标识**：前缀按资源类型固定（如流程为 `bpmn`、决策为 `dmn`、表单为 `ux`），后缀默认是当前时间戳，可改成有意义的英文名。
5. 点击创建。

**预期结果**
* 校验不通过时给出提示：名称为空提示「请输入名称」；标识只允许英文字母、数字和下划线，不能有空格或特殊字符；标识为空提示「请输入标识」。
* 创建成功后**直接打开画布**（新建流程会直接进入编辑状态）。
* 标识是资源跨系统迁移时不变的身份信息，创建后建议不再改动。

:::note[空态有直达入口]
编排目录里还没有任何流程时，右侧引导区会直接显示「新建流程」按钮，点它与目录菜单里的入口是同一条路径。
:::

## 4. 打开与文件操作

**操作步骤**
1. 点击文件树中的任意资源行，资源在右侧打开为页签；顶部「打开的资源」悬浮区可查看当前打开的清单，点「关闭」收起。
2. 需要重命名、下载或删除时，悬停该行点「更多操作」，选择对应动作。
3. 编排目录下的流程、决策目录下的决策，菜单中还有**发布**入口——发布流程见[如何发布评审与部署到引擎](/howto/build/publish/)。

**预期结果**
* 同一资源不会重复开页签；已打开的页签在编辑过程中保持内容。
* 删除会弹出确认，确认后资源从文件树移除。

## 5. 查看已部署的流程定义

**前置条件**
* 在「我的引擎」中至少配置了一台引擎（见[如何维护我的引擎](/howto/build/engines/)）。

**操作步骤**
1. 展开左侧文件树的**运行**段。
2. 用「运行引擎」下拉选择要看哪台引擎（默认选中带「默认」标记的那台）。
3. 列表展开某条流程定义可查看它下面的全部流程定义 Key。
4. 点击某个 Key 行。

**预期结果**
* 运行段列出所选引擎上已部署的流程定义；切换引擎后清单随之刷新。
* 点击 Key 行在**新标签页**打开运行模块的流程定义详情页。
* 尚未配置引擎时空态显示「尚未配置我的引擎」，并给出「打开『我的引擎』」入口；引擎地址或认证有误时，错误提示会指明到「我的引擎」修正哪一项（地址格式、用户名密码或网络跨域）。
* 清单加载失败可重试，不会影响左侧设计资源的使用。
