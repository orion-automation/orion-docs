业务应用是资源的容器。左侧文件树分三段：**发现**（关键发现、原始素材）、**设计**（编排、决策、UX、连接器、业务对象）、**运行**（已部署流程定义）。本篇按三段给出使用大纲，细节后续补充。

## 1. 进入业务应用

**前置条件**
* 已登录 ORION，进入目标工作空间的详情页。

**操作步骤**
1. 在「业务应用」页签中找到目标应用卡片，点击进入。

**预期结果**
* 左侧显示文件树，右侧是内容区；未打开任何文件时显示引导「选择一个文件开始」。

## 2. 认识左侧文件树

**操作步骤**
* 展开/折叠三段与各目录；文件树优先展示服务端已保存的资源，清单未加载完成时先显示本地示例，加载成功后自动替换。

**预期结果**
* **发现**：关键发现、原始素材——梳理阶段沉淀的文档与素材。
* **设计**：编排、决策、UX、连接器、业务对象——五类设计资源的固定目录。
* **运行**：引擎上已部署的流程定义清单（见[第 7 节](#7-运行阶段：查看已部署的流程定义)）。

## 3. 发现阶段：关键发现与原始素材

### 3.1 关键发现

**操作步骤**
1. 悬停「关键发现」目录行 →「更多操作」→ **新建文档**或**新建文件夹**。
2. 也可点**上传文件**把已有文档放进目录。

**预期结果**
* 新建文档走名称与标识对话框（见[第 4 节](#4-设计阶段：五类资源的通用新建规则)），创建后在右侧以文档编辑器打开，用 Markdown 撰写发现结论。

### 3.2 原始素材

**前置条件**
* 需要挂接本机素材目录时，浏览器支持目录关联（否则为只读快照模式）。

**操作步骤**
1. 悬停「原始素材」目录行 →「更多操作」→ **选择本地目录**（已关联时为**重新选择目录**，可**取消关联目录**）。
2. 关联后目录里的子目录与受支持的素材文件进入文件树，子目录逐层展开。
3. 也可**新建文件夹**（建到关联目录根下）与**上传文件**——未关联本地目录时这两项禁用。

**预期结果**
* 关联在会话内可读写，凭权限在下次进入时自动回填；不支持目录关联的浏览器显示**临时打开文件夹**（只读快照，不能写回）。
* 「哪些扩展名算素材」由系统统一判定，不在树里维护。

## 4. 设计阶段：五类资源的通用新建规则

**操作步骤**
1. 悬停目标目录行 →「更多操作」，选择该目录的新建入口：

| 目录 | 新建入口 |
|---|---|
| 编排 | 新建流程 |
| 决策 | 新建决策 |
| UX | 新建表单 |
| 连接器 | 新建 JS Worker、新建 HTTP 接口 |
| 业务对象 | 新建业务对象 |

2. 填写**名称**（必填）。
3. 需要时修改**标识**：前缀按资源类型固定（如流程为 `bpmn`、决策为 `dmn`、表单为 `ux`），后缀默认是当前时间戳，可改成有意义的英文名。
4. 点击创建。

**预期结果**
* 校验不通过时提示：「请输入名称」「请输入标识」「标识只能包含英文字母、数字和下划线，不能有空格或特殊字符。」
* 标识是资源跨系统迁移时不变的身份信息（「该标识将作为未来跨系统迁移时不变的身份标识。」），创建后建议不再改动。
* 创建成功后直接打开对应编辑器（画布、表单设计器、文档编辑器等）。

## 5. 设计阶段：编排

**操作步骤**
1. 「编排」目录 →「更多操作」→ **新建流程**，或**导入 BPMN 文件**引入已有流程。
2. 创建后直接进入画布编辑；编排目录还没有流程时，右侧引导区有直达**新建流程**按钮。
3. 编排目录下的流程行菜单还有**发布**入口（远程资源），见[如何发布评审与部署到引擎](/howto/build/publish/)。

**预期结果**
* 流程是设计段的主资源：编辑、模拟、发布、部署都从这里进入（详见[如何编辑与保存流程](/howto/build/editor/)）。

## 6. 设计阶段：决策 / UX / 连接器 / 业务对象

**操作步骤**
1. **决策**：「新建决策」或**导入 DMN 文件**，创建后打开决策表编辑器。
2. **UX**：「新建表单」或**导入表单文件**，创建后打开表单设计器。
3. **连接器**：菜单里有两条新建入口——**新建 JS Worker** 与**新建 HTTP 接口**（共用同一资源类型、子类型在创建时区分）；另有**从AI 能力中心导入**（把中心的连接器复制成应用内资源）与**导入连接器文件**。
4. **业务对象**：「新建业务对象」或**导入业务对象文件**，创建后打开业务对象编辑器。

**预期结果**
* 各类资源创建后进入各自的编辑器，与编排共用同一套名称/标识校验与打开页签机制（见[第 4 节](#4-设计阶段：五类资源的通用新建规则)与[第 8 节](#8-打开与文件操作)）。

## 7. 运行阶段：查看已部署的流程定义

**前置条件**
* 在「我的引擎」中至少配置了一台引擎（见[如何维护我的引擎](/howto/build/engines/)）。

**操作步骤**
1. 展开左侧文件树的**运行**段。
2. 用「运行引擎」下拉选择要看哪台引擎（默认选中带「默认」标记的那台）。
3. 列表展开某条流程定义可查看它下面的全部流程定义 Key。
4. 点击某个 Key 行。

**预期结果**
* 运行段列出所选引擎上已部署的流程定义；切换引擎后清单随之刷新。
* 点击 Key 行在**新标签页**打开运行模块的流程定义详情页（「点击前往运行页面查看详情」）。
* 尚未配置引擎时空态显示「尚未配置我的引擎」，并给出「打开『我的引擎』」入口；引擎地址或认证有误时，错误提示会指明到「我的引擎」修正哪一项。
* 清单加载失败可重试，不会影响左侧设计资源的使用。

## 8. 打开与文件操作

**操作步骤**
1. 点击文件树中的任意资源行，资源在右侧打开为页签；顶部「打开的资源」悬浮区可查看当前打开的清单，点「关闭」收起。
2. 需要重命名、下载或删除时，悬停该行点「更多操作」，选择对应动作。
3. 编排目录下的流程、决策目录下的决策，菜单中还有**发布**入口。

**预期结果**
* 同一资源不会重复开页签；已打开的页签在编辑过程中保持内容。
* 删除会弹出确认，确认后资源从文件树移除。
