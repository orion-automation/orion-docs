「我的引擎」维护的是**流程应用部署运行所用的云端引擎连接信息**——部署对话框、业务应用的运行段都从这份清单取引擎。本篇覆盖清单的增删改与连通性验证，以及页面下方的流程治理区。

## 1. 新增引擎

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「设计」。

**操作步骤**
1. 在左侧导航点击**我的引擎**。
2. 点击**新增引擎**，按表单填写：
   * **名称**（必填，例如：生产主引擎）——列表里靠它认出这台引擎；
   * **用途**——在下拉中选择（开发 / 测试 / QA / 生产）；
   * **引擎地址**——填引擎服务的根地址（不含 `/engine-rest`），例如 `orion-engine.example.com`；
   * **认证**——需要时填 Basic 认证的用户名与密码（可点**显示密码**核对）；
   * **备注**——例如：生产环境主引擎，用于正式发布；
   * **默认引擎**——按需勾选。
3. 点击**测试连接**，等待结果。
4. 连通后点击**保存**。

**预期结果**
* 测试通过提示「已连通，地址与认证信息均有效。」
* 校验不通过时给出具体原因：名称为空提示「请填写名称 —— 列表里你是靠它认出这台引擎的。」；地址为空提示「请填写引擎地址。」；地址格式不对提示「引擎地址需要是一个 http(s) 地址（含主机名）。」；只填用户名或密码时提示「Basic 认证是一对，只填一半连不上引擎。」
* **保存前必须先通过连通性测试**，否则提示「请先通过连通性测试再保存。」
* 保存成功后引擎出现在清单中，带列：名称、用途、引擎地址、认证、备注；默认引擎带**默认**标记。

:::tip[地址怎么填]
填**引擎根地址**，不要带 `/engine-rest`；协议前缀已固定在输入框上，不需要重复输入。
:::

## 2. 连通性测试的失败怎么读

**操作步骤**
* 在新增或编辑表单中点击**测试连接**，对照提示排查。

**预期结果**（每条都指明了下一步）
* 「请先填一个 http(s) 地址，这行现在还测不了。」——地址还没填或格式不对。
* 「认证没通过（引擎回了 401）。检查用户名与密码；若确实是空的，也可能这台引擎不接受 Basic 认证。」
* 「主机连上了，但这个路径上没有引擎接口（404）。检查地址是否漏了 `/engine-rest`，或者多带了别的路径。」——测试接口的路径规则与部署地址不同，按提示补齐或删减。
* 「服务在，但拒绝了这次请求。请联系这台引擎的管理员。」
* 「连不上：地址写错、服务未启动、或浏览器跨域（CORS）被拦。这三种在浏览器里报的是同一个错，无法区分，请依次排查。」
* 「这个地址有响应，但回的内容不像引擎接口……请确认它指向的是引擎服务，而不是门户或网关。」

## 3. 编辑与删除引擎

**操作步骤**
1. 在清单中目标行打开操作菜单，选择**编辑引擎**。
2. 修改字段后，同样先**测试连接**再**保存**。
3. 需要移除时，同一菜单选择**删除**，在确认框中核对后确认。

**预期结果**
* 编辑保存后，部署对话框与运行段立即使用新的连接信息。
* 删除确认文案为「确定删除引擎「`{name}`」？此操作不可撤销。」，确认后该行从清单消失。
* 未配置任何引擎时，空态显示「还没有维护过引擎」，并说明「把你要管理的引擎加进来，之后就能在一个地方看到它们。」。

## 4. 理解凭据保存位置

**操作步骤**
* 读一读表单下方的**凭据安全**说明。

**预期结果**
* **用户名与密码仅保存在本机浏览器**，不会上传或同步到服务器。
* 清单中的其它信息（名称、用途、地址、备注、默认标记）**随账号同步**——换设备后这些信息在，但凭据要重新填写。
* 若保存时本机拒绝写入凭据，会提示「引擎已保存，但用户名 / 密码没能存进本机（浏览器拒绝了写入），下次打开这台引擎时需要重新填写。」——引擎条目本身已生效，只需下次打开时补填。
* 取不到登录态时提示「取不到当前登录账号，无法读写你的引擎清单。请重新登录后再试。」；服务端请求失败提示「服务端请求失败（网络不通或服务已拒绝），本次改动没有生效，请稍后重试。」，可点**重试**。

:::note[默认引擎只有一个]
勾选某台为默认引擎后，部署对话框与运行段会优先选中它；同一清单里默认标记只会落在一台上。
:::

## 5. 流程治理：维护我的业务架构

「我的引擎」页面下方的**流程治理**区有两个页签，第一个是**我的业务架构**——定义业务域与流程集合的编码规则，并管理其启用范围。它与上面的引擎清单是独立的一块，有自己的保存状态。

**前置条件**
* 已登录 ORION，进入「设计 › 我的引擎」，页面滚动到底部的**流程治理**区。

**操作步骤**
1. 确认当前在**我的业务架构**页签。
2. 用搜索框定位业务域或流程集合（搜索词匹配名称）。
3. 按需调整：
   * 行内**启用**开关——控制该流程集合是否参与流程编码；业务域行的开关会联动其下全部流程集合（「启用该业务域下的全部流程集合」）；
   * **新增业务域** / **新增流程集合**——在树上追加条目；
   * **编码**列填写规则——业务域编码（英文简称，用于拼接流程 Key）、流程集合编码（用于拼接流程 Key）；
   * **当前序号**——下一个流程使用的流水号。
4. 改动即时保存，统计行里出现「已保存」回执（读取失败或保存失败时该处显示红字原因）。

**预期结果**
* 列表列：启用、业务域 / 流程集合、编码、当前序号、流程编码预览、操作；表尾统计「已启用 `{enabled}` / `{total}`」。
* 编码规则校验：**编码需以字母开头，只能包含大写字母和数字，最长 8 位**；编码重复时提示「编码重复，会生成相同的流程 Key」。
* **流程编码预览**按 `<业务域编码>_<流程集合编码>_<流水号>` 拼出（流水号补足 4 位，例如 `HR_G01_0001`）；编码不完整时预览显示「编码不完整」。
* 顶部可一键**全部启用** / **全部禁用**——全部禁用有二次确认：「将关闭全部 `{total}` 个流程集合的启用开关，已收起和不在搜索结果里的条目同样会被关闭。撤销需要逐项重新勾选。」；**全部展开** / **全部收起**折叠整棵树。
* 删除行需确认「确定删除「`{name}`」？此操作不可撤销。」。
* 读取失败时提示「配置读取失败，当前显示默认设置」，保存失败时提示「保存未生效，请稍后重试」。

:::note[业务架构存放在哪里]
这套配置保存在**当前浏览器本地、按登录账号隔离**，不随账号同步到服务器；换设备或清除站点数据后需要重新配置。
:::

## 6. 流程治理：维护流程 KPI 定义库

流程治理区的第二个页签是**流程 KPI 定义库**——定义流程绩效指标的基本信息、计量口径与目标值（本阶段只管定义，不算数、不取数）。

**前置条件**
* 已登录 ORION，进入「设计 › 我的引擎」，滚动到底部**流程治理**区并切到**流程 KPI 定义库**页签。
* 库为空时会自动带入 5 条行业参考指标（电信口径，五种指标类型各一条，3 条已发布 + 2 条草稿），可照着改或删。

**操作步骤**
1. 点击**新建指标**，填写表单：
   * **指标名称**（必填，例如 订单到收款周期）；
   * **指标编码**（必填，唯一标识，创建后不可修改；例如 `O2C_CYCLE_TIME`；只能包含字母、数字、下划线或连字符，最长 40 位）；
   * **指标分类**——效率 / 质量 / 成本 / 合规 / 其他；
   * **指标类型**——时长 / 数量 / 金额 / 比率 / 评分；
   * **计量单位**——小时 / 天 / 分钟 / 次 / 元 / `%` / 分（发布前必填）；
   * **指标描述**、**计算公式**（选填，例如 `SUM(已回款订单金额) / COUNT(订单数)`）；
   * **BI 超链接**（选填，须为 `http/https` 地址，指向该指标的 BI 报表或看板）；
   * **指标负责人**、**目标值**（须为数字）、**指标方向**（越高越好 / 越低越好 / 区间最优）。
2. 点击**保存**。
3. 校验通过后点**发布**让指标可被流程绑定；需要改回时同一行选**转为草稿**。
4. 定位用顶部搜索（名称或编码，空格分词）与**全部分类** / **全部状态**筛选。

**预期结果**
* 列表列：指标名称、指标编码、指标分类、指标类型、计量单位、指标负责人、状态、更新时间、BI 报表、操作；表尾统计「共 `{total}` 条 · 已发布 `{published}` 条」。
* 状态两档：**草稿** / **已发布**；发布缺必填项时提示「请先补全必填项再发布」。
* 删除需确认「确定删除「`{name}`」？此操作不可撤销。」；已被流程引用的指标删除被拦下，提示「「`{name}`」已被流程引用，不能删除」。
* 空态显示「还没有指标」，并引导「新建第一项指标，定义它的分类、类型与目标值」。

:::note[KPI 定义库存放在哪里]
指标库保存在**当前浏览器本地、按登录账号隔离**，不随账号同步；但**流程文档里已绑定的 KPI** 随资源保存、随版本走，见下方第 7 节。
:::

## 7. 把 KPI 绑定到流程文档

**前置条件**
* 指标已在定义库中**发布**（只有已发布指标可绑定）。
* 已在业务应用中打开一条 BPMN 流程，进入编辑器。

**操作步骤**
1. 点击编辑器工具条上的**流程文档**，打开文档面板。
2. 在文档工具条点击**流程 KPI**，右侧出现绑定区——已绑定的指标以胶囊排在上方。
3. 点绑定区的**编辑**，打开绑定对话框：左侧从定义库勾选要绑定的指标，右侧调整每条绑定的 **BI 超链接**（留空则沿用定义库地址，可点**恢复默认**；也可填本流程自定义地址，须以 `http://` 或 `https://` 开头）。
4. 点击**保存**。

**预期结果**
* 绑定后的指标以胶囊形式常驻文档正文上方；点胶囊打开**指标详情**，点**打开 BI 报表**在新标签页跳转看板。
* 每条绑定的 BI 超链接**随流程文档保存**——换设备打开这份流程、出在线版本、「另存为」都带着它。
* 定义库里的指标被删除后，胶囊显示「已失效」，详情里保留绑定时拍的快照（「该指标已从定义库移除，以下为绑定时的信息」）。
* 定义库读取失败时不猜：胶囊退回绑定时的快照，并显示读取失败提示。
