README 是工作空间的说明页，协作人决定谁能进入这个空间。两者都从详情页维护。

**前置条件**
* 已登录 ORION，进入目标工作空间的详情页。

## 1. 撰写 README

**操作步骤**
1. 打开 README 抽屉（总览卡「完整阅读」或页内入口），点**编辑**。
2. 用 Markdown 撰写工作空间说明——应用背景、环境依赖或版本契约。
3. 写完点保存；放弃修改前离开会提示「README 还有未保存的修改，确定放弃吗？」。

**预期结果**
* 编辑位有**返回预览**切换；占位提示「在这里撰写工作空间说明（支持 Markdown）…」。
* README 内容随工作空间保存；抽屉空态提示「暂无 README 内容，点击右上角「编辑」开始撰写。」
* 加载失败时提示「README 加载失败，请检查网络或稍后重试。」

## 2. 管理协作人

**操作步骤**
1. 点「管理协作人」，在搜索框输入姓名或邮箱查找人员并添加。
2. 对已加入的协作人可调整角色或移出。

**预期结果**
* 角色共四档：**负责人 / 管理者 / 编辑者 / 评论员**。
* 搜索框的提示按状态切换，**共三句**，顺序如下：
  1. 还没输入关键字——「输入姓名或邮箱以搜索人员」；
  2. 输入了关键字但引擎没回匹配的人——「没有找到匹配的人员」；
  3. 引擎回满一批候选、却全都是已经在空间里的人——「匹配到的人都已经在这个工作空间里了，继续输入可缩小范围」。
* 第 3 句只在**一次搜索取回的候选被排空**时出现。只搜一个人（哪怕他已经在空间里）通常取不满一批，看到的会是第 2 句。
* 加人成功但该工作空间还没有对应的成员组时，给黄色提示「协作人已加入，但该工作空间还没有对应的成员组，对方暂时看不到它」——此时人已加上，只是对方还看不到。
* 增删改角色失败分别提示「添加协作人失败，请稍后重试」「移出协作人失败，请稍后重试」「修改角色失败，请稍后重试」，可重试；把对方加入成员组那一步失败时提示「未能把对方加入工作空间成员组，请确认账号是否有修改成员组的权限」。
