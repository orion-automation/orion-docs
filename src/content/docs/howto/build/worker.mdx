**前置条件**
* 已在「外部执行器」分类创建模板并进入详情页。

**操作步骤**
1. **基本信息**页签填说明、标签、版本标签。
2. **配置信息**页签填写：
   * **Topic 名称**（必填）——对应 BPMN 中 External Task 节点的 Topic 值，例如 `process-order`；只能含字母、数字、下划线、点、冒号和横线；
   * **输入变量**表逐行录入——对应 External Task 节点的输入变量，运行时作为局部变量传给 Worker：**变量名**（落到引擎侧的局部变量）、**显示名**（给人看的名字，如「订单编号」，不会写进流程）、**必填**（勾选后没填值会作为问题报出来）、**取值方式**（常量 / 变量 / 表达式 / 脚本）与**值**。
3. 用**导入** / **导出**按钮在机器间搬模板（导出文件带 `orionWorkerTemplate` 标记；应用资源的 `.orion-worker` 是运行时定义，两者不能互换）。

**预期结果**
* 保存前的预览「这一步会发给引擎什么」显示最终 Topic 与各参数；填几个示例值就能看到变量 / 表达式会解析成什么。
* **在流程设计中**：
  1. 画布上放置 External Task 类型的服务任务，属性面板「常规」分组的**快速设置**下拉切到「能力中心」页签选中该模板（无需先导入应用；两边都有内容时才出现页签，只有一边时直接显示列表）；
  2. 节点顶部的**模板参数**区显示同步状态——「与模板一致」，或提示「主题与模板不一致（模板：`{topic}`）—— 对不上的话引擎永远不会派发这个节点」，可点**对齐主题**或**补齐**一键修正，点**在能力中心打开**跳回模板。
