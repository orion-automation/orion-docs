实验室是试验性工具的入口：先把想法跑起来，再决定要不要变成产品能力。当前提供两件工具——**客户旅程图**与**服务蓝图**，数据保存在当前浏览器本地。

## 1. 进入工具与查看清单

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「设计」。

**操作步骤**
1. 在左侧导航点击**实验室**。
2. 在「可用工具」区点**客户旅程图**或**服务蓝图**，进入该工具的清单页。
3. 清单页列出已有图，卡片上显示数量标记「已有 `{n}` 张」。

**预期结果**
* 旅程图空态显示「还没有旅程图」，并说明「从空白骨架开始，或用示例看一遍『情绪曲线怎么读』。一张图只讲一个角色的一个场景。」
* 服务蓝图空态显示「还没有服务蓝图」，并说明可从空白骨架开始、用示例看四层结构，或从已有旅程图导入阶段与客户行为直接续写后台。

## 2. 新建一张图

**操作步骤**
1. 在清单页点击**新建旅程图**（或**新建服务蓝图**）。
2. 填写**名称**（旅程图例如：新客户开通专线；服务蓝图例如：家电零售 · 到店购买）。
3. 选择**起点**模板：
   * **空白骨架**——自己填内容；
   * 示例（旅程图为「示例：换手机套餐」，服务蓝图为「示例：家电零售到店购买」）——带完整示例数据。
4. 服务蓝图还可以点**或从旅程图导入**，从已有旅程图带入阶段与客户行为。
5. 点击**创建**。

**预期结果**
* 创建后直接进入编辑画布。
* 服务蓝图从旅程图导入时，新图名称自动带上「· 服务蓝图」后缀，阶段数显示为「`{n}` 个阶段」。
* 导入旅程图失败时提示「读不了这份文件：请确认它是从旅程图工具导出的 JSON。」（服务蓝图对应提示会写明「从服务蓝图工具导出」）。

## 3. 导出与复制

**操作步骤**
1. 在清单页目标卡片的操作菜单中：
   * 旅程图：选择**导出 JSON**（或**复制**出一份副本）。
   * 服务蓝图：选择**导出 JSON**，子菜单中还可选**导出图片（PNG）**、**导出矢量（SVG）**、**导出数据（JSON）**。
2. 需要分享给他人编辑时，用**复制**生成「`{name}` 副本」再改名。

**预期结果**
* 导出文件按所选格式下载；JSON 可再通过**导入**回到清单。
* 复制出的副本与原图相互独立。

## 4. 导入与删除

**操作步骤**
1. **导入**：清单页点**导入**，选择之前导出的 JSON 文件。
2. **删除**：目标卡片操作菜单 → **删除**，在确认框中核对后确认。

**预期结果**
* 导入成功后新图出现在清单中。
* 删除确认文案为「『`{name}`』将被永久删除，不能恢复。」，确认后卡片消失。
* 文件格式不对时给出读取失败提示（见第 2 节）。

:::caution[数据保存在当前浏览器]
两件工具的图都保存在**当前浏览器本地**，不随账号同步；换浏览器或清站点数据后图不在。环境不支持本地存储时会提示这张图只在本次会话内有效——重要成果请用**导出 JSON**留档。
:::

## 5. 画布内的常用操作

**操作步骤**
* 编辑过程中用**撤销** / **重做**回退或恢复。
* 完成后点**返回列表**回到该工具的清单，或点**返回实验室**回到工具选择页。

**预期结果**
* 撤销历史按操作步进回退；返回清单后卡片上的阶段数、动作数等统计随之更新。
* 读取数据中显示「正在读取数据…」；失败提示「读取数据失败，可点**重试**」。
