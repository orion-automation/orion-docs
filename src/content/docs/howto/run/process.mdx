流程定义面板回答两个问题：哪条流程在跑、跑得怎么样；实例视图回答：具体哪个实例出了事。

## 1. 打开流程定义面板

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。

**操作步骤**
1. 在左侧导航点击「流程定义」。
2. 用搜索框按流程名称或定义 Key 过滤，或点右侧「流程实例查询」进入实例视图（见第 3 节）。

**预期结果**
* 列表展示流程名称、流程定义 Key、运行实例、已完成、故障、提醒与操作。
* 顶部快捷筛选可只看「有运行实例」「有故障」「需关注」的流程；页签上带各自计数。

## 2. 查看单条流程的运行概览

**操作步骤**
1. 点击列表中的目标流程行，进入该流程定义的详情页。
2. 在「概览」区核对定义版本、故障数、运行中实例数、作业与变量。
3. 查看「流程实例运行走势」折线与「当前节点」标注；需要看图上位置时打开「地图」。

**预期结果**
* 概览数字与列表列一致；走势反映当前页实例的起止趋势。
* 变量区提示「选择一个流程实例以查看变量」时，先在实例区选中一个实例。

## 3. 查询流程实例

**操作步骤**
1. 在流程定义面板点击「流程实例查询」，或从流程详情进入实例视图。
2. 快速定位：把流程实例 ID 粘贴进顶部输入框，列表自动查询——快速搜索优先于并叠加在高级条件之上。
3. 需要组合条件时，点「设置查询条件」打开对话框，按页签逐组填写（多个条件将同时生效）：
   * **标识与定义**：实例标识（实例 ID、ID 列表、排除 ID）与流程定义（定义 Key、名称包含、定义 ID）；
   * **业务、状态与事故**：业务键、实例状态（不限状态、未结束、已结束、活跃、已挂起、已完成、外部终止、内部终止）、发起人、租户 ID，以及仅显示存在事故的实例；
   * **时间范围**：按时间收窄；
   * **关系与活动**：父子流程与 Case 关系、按当前节点收窄；
   * **变量与 OR**：按变量值收窄（专家选项）。
4. 核对条件后点「查询」；点「重置条件」清空全部条件，点「取消」关闭对话框。

**预期结果**
* 列表底部显示「共 `{条数}` 条结果」；修改条件后结果自动刷新。

## 4. 查看实例详情

**操作步骤**
1. 在实例列表点击目标实例，进入实例详情页。
2. 在运行时视图查看页签：概览、变量、故障、调用的流程实例、Job工作、人工任务、外部任务。
3. 已结束的实例可切到历史视图，额外看到执行的决策实例、Job日志与历史任务等页签。
4. 工具条右侧点「刷新」重新拉取，点「自动刷新」开启每 3 秒自动刷新（再点暂停）；点「定义版本 `vN`」按钮（悬停提示「返回流程定义」）回到上一级。

**预期结果**
* 运行时页签反映当前状态，历史页签反映已归档记录；两者位置对应的页签保持一致。
* 故障页签列出该实例的故障记录，可据此进入 [如何处理作业与线程池](/howto/run/job/) 排查。
