运行看板是排查的起点：先看概览卡片确认哪类对象异常，再下钻到对应子视图定位具体记录。

**前置条件**
* 已登录 ORION。运行模块对登录用户开放，无额外权限要求。

**操作步骤**
1. 点击顶部栏左侧的「打开应用菜单」按钮。
2. 在展开的导航抽屉中点击「运行」。
3. 页面默认停在「看板」；若停在其他面板，点击左侧导航的「看板」。

**预期结果**
* 面包屑显示「运行 > 看板」。
* 页面自上而下依次是三块：**运行概览**（九张计数卡）、**运行趋势**（折线图）、**故障流程清单**（底部表格）。

## 三块结构怎么读

| 区块 | 回答什么问题 | 详见 |
| --- | --- | --- |
| 运行概览 | 哪一类对象异常，点卡片能下钻到哪里 | [如何查看运行概览卡片与子视图](/howto/run/dashboard/cards/) |
| 运行趋势 | 某个指标随时间怎么走 | [如何查看运行趋势](/howto/run/dashboard/trends/) |
| 故障流程清单 | 哪些实例卡在故障上还没结束 | [如何查看故障流程清单](/howto/run/dashboard/incidents/) |
