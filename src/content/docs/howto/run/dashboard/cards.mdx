title: 如何查看运行概览卡片与子视图
description: 如何在 ORION 运行看板读取运行概览的九张计数卡，以及每张卡点击后打开的看板内子视图与其他面板。
---

「运行概览」是九张计数卡。带异常标记的几张（故障事件、含故障或挂起的流程实例、无重试剩余的作业、含失败的批处理）优先看。

**前置条件**
* 已进入运行看板，见 [如何查看运行状态与故障事件](/howto/run/dashboard/)。

## 认识九张计数卡

**操作步骤**
1. 在「运行概览」卡片中，自左至右、自上而下核对九张计数卡。
2. 点击任意一张卡片，页面跳转到对应的子视图或面板。
3. 从子视图返回看板时，点击左侧导航的「看板」。

**预期结果**

| 卡片 | 计数构成 | 点击后去哪 |
| --- | --- | --- |
| 智能体任务 | 含故障、挂起 | 看板内子视图 |
| 故障事件 | 作业、外部任务 | 看板内子视图 |
| 事件订阅 | 消息、信号 | 看板内子视图 |
| 流程实例 | 总数、含故障、挂起 | 「流程定义」面板 |
| 人工任务 | 总数、挂起 | 看板内子视图 |
| 外部任务 | 总数、锁定、挂起 | 看板内子视图 |
| 作业 | 总数、无重试剩余、挂起 | 看板内子视图 |
| 批处理 | 总数、挂起、含失败 | 「批处理」面板 |
| 部署 | 流程定义、决策定义 | 「部署」面板 |

* 智能体任务卡的悬停说明是「正在运行的智能体任务调用（按业务流程查看）」。
* 流程实例、批处理、部署三张卡不进子视图，而是切到左侧已有的面板。

## 打开看板内子视图

### 智能体任务

**操作步骤**
1. 点击「智能体任务」卡。
2. 用搜索框按业务流程或实例过滤，点「刷新」拉取最新数据。

**预期结果**
* 列出业务流程、业务流程实例、智能体任务、状态、开始时间与已运行时长。
* 只列**正在运行**的调用；已结束的不在此清单。

### 故障事件

**操作步骤**
1. 点击「故障事件」卡。
2. 用顶部的类型筛选在「全部」「作业」「外部任务」之间切换。
3. 用搜索框按名称或 ID 过滤。
4. 点击某条记录查看故障详情，看完点「关闭详情」收起。

**预期结果**
* 列表列出类型、流程定义、流程实例、失败活动与发生时间；类型筛选旁带该类型的计数。
* 详情里可看到故障发生的活动位置、流程上下文与引擎返回的消息。

:::caution[AI 解读暂未上线]
故障详情中的「AI 解读（即将上线）」入口当前不可用，排查仍以详情字段为准。
:::

### 事件订阅

**操作步骤**
1. 点击「事件订阅」卡。
2. 按事件名称搜索，或按创建时间排序。
3. 点击某条查看订阅详情。

**预期结果**
* 列出事件名称、事件类型、活动 ID、流程实例、执行 ID 与创建时间。
* 事件类型包含消息、信号、补偿与条件等；详情里带租户与订阅 ID。

### 人工任务

**操作步骤**
1. 点击「人工任务」卡。
2. 按任务名称或负责人过滤，点「刷新」拉取最新数据。

**预期结果**
* 列出任务名称、负责人、创建时间、到期时间、优先级与活动 ID。
* 点击某条可看到办理人、到期时间与所属实例。

### 外部任务

**操作步骤**
1. 点击「外部任务」卡。
2. 按主题或状态过滤，需要时点行内「重试」重置该任务的重试次数。

**预期结果**
* 列出主题、状态、剩余重试、活动 ID、流程定义、流程实例、创建时间与锁定到期时间。
* 状态有**可用**、**已锁定**、**已挂起**三种。

### 作业

**操作步骤**
1. 点击「作业」卡。
2. 按状态或流程实例过滤，需要时点行内「重试」把失败作业推回队列。
3. 点击某条查看作业详情。

**预期结果**
* 列出状态、剩余重试、失败活动、流程定义、流程实例与创建时间。
* 状态有**就绪**、**重试耗尽**、**已挂起**三种；「重试耗尽」的作业不会再自动执行。
