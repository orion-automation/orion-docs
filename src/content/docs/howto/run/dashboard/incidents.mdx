title: 如何查看故障流程清单
description: 如何在 ORION 运行看板底部的故障流程清单里按类型筛选未结束的带故障实例，并跳到实例或定义详情。
---

「故障流程清单」列出**存在故障尚未结束的流程实例**——它们是当前最该处理的一批。

**前置条件**
* 已进入运行看板，见 [如何查看运行状态与故障事件](/howto/run/dashboard/)。
* 位于页面底部的「故障流程清单」区块。

**操作步骤**
1. 滚动到页面底部的「故障流程清单」区块。
2. 用区块右上角的「全部 / 作业 / 外部任务」页签按故障类型筛选，页签上带各自计数。
3. 点「开始时间」列头切换排序。
4. 点实例 ID 打开该实例详情；点流程定义跳到该定义的详情页。
5. 数据不是最新时点「刷新」重新拉取。

**预期结果**
* 列表列出状态、实例 ID、业务键、流程定义与开始时间。
* 只列未结束且带故障的实例；已结束的不在此清单。
* 所选类型没有记录时显示「当前没有未结束且含故障的流程实例」，属于正常空态。

:::caution[这里只列「还没结束」的]
故障已随实例结束而消失的，不会出现在这张表。要查历史故障，去 [如何查看进行时视图](/howto/run/process/runtime/) 的故障页签或 [如何查看历史视图](/howto/run/process/history/)。
:::
