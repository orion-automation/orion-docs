---
title: 如何查看运行趋势
description: 如何在 ORION 运行看板的运行趋势里选时间范围与指标组，读取折线图并处理加载失败与空数据。
---

「运行趋势」把引擎的计数指标按时间画成折线，用来判断某个指标是在变好还是变坏。

**前置条件**
* 已进入运行看板，见 [如何查看运行状态与故障事件](/howto/run/dashboard/)。
* 位于页面中部的「运行趋势」卡片。

**操作步骤**
1. 先选时间范围：**今日**、**7天** 或 **自定义**。
2. 在指标下拉中选指标组，再选具体指标。
3. 图表按所选范围与指标绘制趋势线。
4. 指标加载失败时点「重新加载」。

**预期结果**
* 所选范围没有数据时显示「当前范围暂无指标数据」，属于正常空态。
* 加载失败时显示「指标数据加载失败」，点「重新加载」重取，不影响看板其余部分。

## 四个指标组

| 指标组 | 指标 |
| --- | --- |
| 流程与活动 | 流程实例、活动实例启动、活动实例结束、流程节点实例 |
| 作业执行 | 作业获取尝试、作业获取成功、作业获取失败、作业执行拒绝、作业成功、作业失败、独占作业锁定 |
| 决策 | 决策实例、已执行决策元素 |
| 历史清理 | 已清理流程实例、已清理案例实例、已清理决策实例、已清理批处理操作、已清理任务指标 |

:::note[读图的常见问法]
看**作业失败**与**作业成功**的相对走势，比单看一条更能说明执行质量；**历史清理**一组只在清理任务跑过之后才有值。
:::
