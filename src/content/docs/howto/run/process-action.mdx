本篇覆盖流程定义详情页顶部的四个动作入口与删除操作。四个动作都会先让你预览将要提交的请求，确认后才执行。

## 1. 启动一个新实例

**前置条件**
* 已进入目标流程定义的详情页。

**操作步骤**
1. 点击顶部「启动流程」。
2. 按需填写 **业务键（可选）**——用于把实例与业务单据关联。
3. 在变量区添加启动变量；单个变量可点「删除这个变量」移除。
4. 需要从非默认位置开始时，在「从哪里开始」添加启动指令；不添加则按流程默认起点开始。
5. 按需勾选选项：跳过 IO 映射、跳过自定义监听器、返回变量。
6. 点「查看将要提交的请求」核对 JSON，再点「确认启动流程实例」。

**预期结果**
* 创建成功后页面显示新实例的关键信息；业务键存在时一并展示。
* 确认区提示按指令开始还是按默认起点开始。

## 2. 迁移实例到新版本

**操作步骤**
1. 点击顶部「迁移」，进入流程迁移页。
2. 选择源流程与目标流程（源通常自动带入当前版本）。
3. 在计划区核对元素映射；需要调整时点击对应映射修改，可用撤销/重做回退计划编辑。
4. 需要给实例注入变量时，在变量页签添加。
5. 核对影响范围与请求预览后执行。

**预期结果**
* 迁移计划列出每个实例的映射结果；被移除的计划可用「恢复」找回。
* 执行后目标版本的实例按新定义继续运行。

:::caution[先小批量再全量]
迁移会改变运行中实例的走向。建议先用少量实例验证映射，再放开范围。
:::

## 3. 编辑运行中实例（流程编辑）

**操作步骤**
1. 点击顶部「流程编辑」，进入流程编辑页。
2. 添加编辑指令（如取消某个活动、跳过某个节点）；被锁定的实例会在摘要中单独列出。
3. 核对请求预览与影响范围后执行。

**预期结果**
* 指令按顺序应用到匹配的实例；不完整的指令会被拦截并提示。
* 已锁定的实例不会被改动，摘要中可见。

## 4. 重启已结束实例（流程重启）

**操作步骤**
1. 点击顶部「流程重启」，进入流程重启页。
2. 搜索并勾选要重启的实例。
3. 选择目标版本，按需设置初始变量与选项（跳过 IO 映射、跳过自定义监听器、不含业务键等）。
4. 核对影响范围与请求预览后执行。

**预期结果**
* 被选实例按目标版本重新进入运行状态；空选择会被拦截并提示。

## 5. 删除定义或实例

**前置条件**
* 删除不可撤销，执行前确认影响范围。

**操作步骤**
1. 在流程定义详情点击「更多操作」。
2. 按需选择：
   * **删除流程定义**：删除该流程的定义；确认框中可勾选级联选项。
   * **删除运行实例**：删除仍在运行的流程实例，并连同其运行时与历史数据一起清理。
   * **删除已完成流程实例**：只删已结束实例的历史记录。
3. 在确认框中核对目标名称后确认。

**预期结果**
* 列表与统计立即刷新；运行中实例的删除可在实例视图中复核。
