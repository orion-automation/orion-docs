---
title: 如何模拟决策
description: 如何在 ORION 决策详情页打开模拟面板，选择决策、填写输入上下文并执行评估，读取命中结果。
---

模拟给这一版已部署的决策表喂一组输入，看它命中哪条规则——不用真的跑一个流程实例。

**前置条件**
* 已进入目标决策的详情页，见 [如何查看决策定义与决策历史](/howto/run/decision/)。
* 该版本包含至少一个可评估的决策表。

**操作步骤**
1. 在详情页工具栏点「模拟」，面板展开（按钮同时高亮；再点一次收起）。
2. 在「选择决策」里选中要试算的那一条。
3. 在「输入上下文（JSON）」里填入这组输入，例如 `{"age": 21, "risk": "LOW"}`。
4. 需要时点「格式化」整理缩进。
5. 点「执行评估」。

**预期结果**
* 「评估结果」区列出这次输入命中了哪条规则、输出是什么。
* 没有规则命中时显示「（未命中任何规则）」——通常是输入没落进任何条件区间。

## 输入不被接受时

| 提示 | 怎么办 |
| --- | --- |
| 输入上下文不是有效的 JSON | 检查引号、逗号与括号是否配对 |
| 输入上下文必须是 JSON 对象 | 顶层要用 `{}` 包住，不能是数组或裸值 |
| 当前 DMN 中没有可评估的决策表 | 这一版只含其他类型的决策元素，换一个定义 |
| 当前 DMN 无法导出 XML | 模型读不出来，先确认详情页画布能正常显示 |

:::note[模拟不写入任何数据]
模拟只是在面板里试算：不改动已部署的决策，也不会产生决策记录。决策历史只收录真实执行过的评估，见 [如何查看决策定义与决策历史](/howto/run/decision/)。
:::

:::tip[两处的模拟不是同一个版本]
设计模块的决策编辑器里也有同一块面板，那边试算的是画布上**当前未保存**的内容；运行模块这边试算的是**已部署**的这一版。对不上时先确认你在哪一侧。
:::
