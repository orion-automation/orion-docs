运行看板是排查的起点：先看概览卡片确认哪类对象异常，再下钻到对应子视图定位具体记录。

## 1. 进入运行看板

**前置条件**
* 已登录 ORION。运行模块对登录用户开放，无额外权限要求。

**操作步骤**
1. 点击顶部栏左侧的「打开应用菜单」按钮。
2. 在展开的导航抽屉中点击「运行」。
3. 页面默认停在「看板」；若停在其他面板，点击左侧导航的「看板」。

**预期结果**
* 面包屑显示「运行 > 看板」；页面自上而下依次是「运行概览」「运行趋势」「故障流程清单」。

## 2. 读取运行概览卡片

**操作步骤**
1. 在「运行概览」卡片中，自左至右、自上而下核对八张计数卡。
2. 关注带异常标记的计数：故障事件、含故障或挂起的流程实例、无重试剩余的作业、含失败的批处理。

**预期结果**
* **故障事件**：按作业与外部任务两类分列计数。
* **流程实例**：总数，附「含故障」「挂起」两个细分计数。
* **人工任务**：总数，附「挂起」计数。
* **外部任务**：总数，附「锁定」「挂起」计数。
* **作业**：总数，附「无重试剩余」「挂起」计数。
* **批处理**：总数，附「挂起」「含失败」计数。
* **部署**：按流程定义与决策定义分列计数。
* **事件订阅**：按消息与信号分列计数。

## 3. 从卡片下钻到子视图

**操作步骤**
1. 点击任意概览卡片，页面跳转到对应的面板或子视图。
2. 从子视图返回看板时，点击左侧导航的「看板」。

**预期结果**
* 故障事件卡进入看板的「故障事件」子视图；事件订阅、作业、外部任务、人工任务四张卡同理。
* 流程实例卡进入「流程定义」面板；批处理卡进入「批处理」面板；部署卡进入「部署」面板。

## 4. 查看故障事件子视图

**操作步骤**
1. 进入「故障事件」子视图后，用顶部的类型筛选在「全部」「作业」「外部任务」之间切换。
2. 在列表中核对每条故障的类型、流程定义、流程实例、活动、消息与时间。
3. 点击某条记录查看故障详情，看完点「关闭详情」收起。

**预期结果**
* 列表只显示所选类型的故障；类型筛选旁显示该类型的计数。
* 详情中可看到故障发生的活动位置与引擎返回的消息。

:::caution[AI 解读暂未上线]
故障详情中的「AI 解读（即将上线）」入口当前不可用，排查仍以详情字段为准。
:::

## 5. 查看运行趋势

**操作步骤**
1. 在「运行趋势」卡片中，先选时间范围：今日、7天或自定义。
2. 在指标下拉中选择指标组——流程与活动、作业执行、决策、历史清理——再选具体指标。
3. 指标加载失败时点击「重新加载」。

**预期结果**
* 图表按所选范围与指标绘制趋势线。
* 所选范围没有数据时显示「当前范围暂无指标数据」，属于正常空态。

## 6. 查看故障流程清单

**操作步骤**
1. 滚动到页面底部的「故障流程清单」区块。
2. 用区块右上角的「全部 / 作业 / 外部任务」页签按故障类型筛选，页签上带各自计数。
3. 在列表中核对状态、实例 ID、业务键、流程定义与开始时间。

**预期结果**
* 区块副标题为「存在故障尚未结束的流程实例」，只列未结束且带故障的实例。
* 所选类型没有记录时显示「当前没有未结束且含故障的流程实例」，属于正常空态。

## 7. 切换其他子视图

**操作步骤**
1. 从概览卡片进入事件订阅、作业、外部任务或人工任务子视图。
2. 在子视图中使用搜索框按名称或 ID 过滤，点击刷新按钮获取最新数据。

**预期结果**
* 作业子视图按状态（就绪、重试耗尽、已挂起）与剩余重试展示排队中的作业。
* 事件订阅子视图按创建时间排序，可搜索消息或信号名称。
