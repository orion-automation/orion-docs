---
title: 如何迁移流程实例
description: 如何在 ORION 流程定义详情把运行中的实例从一个版本迁到另一个版本，核对元素映射并执行。
---

**前置条件**
* 已进入目标流程定义的详情页，并切到**进行时视图**——迁移的对象是还在运行的实例。

**操作步骤**
1. 点击顶部「迁移」，进入流程迁移页。
2. 选择源流程与目标流程（源通常自动带入当前版本）。
3. 在计划区核对元素映射；需要调整时点击对应映射修改，可用撤销与重做回退计划编辑。
4. 需要给实例注入变量时，在变量页签添加。
5. 核对影响范围与请求预览后执行。

**预期结果**
* 迁移计划列出每个实例的映射结果；被移除的计划可用「恢复」找回。
* 执行后目标版本的实例按新定义继续运行。

:::caution[先小批量再全量]
迁移会改变运行中实例的走向。建议先用少量实例验证映射，再放开范围。
:::
