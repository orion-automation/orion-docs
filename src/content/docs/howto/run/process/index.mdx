---
title: 如何打开流程定义详情
description: 如何在 ORION 运行模块从流程定义列表进入详情页，并认识流程图、工具栏与定义信息条。
---

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。

**操作步骤**
1. 在左侧导航点击「流程定义」。
2. 用搜索框按流程名称或定义 Key 过滤。
3. 点击列表中的目标流程行，进入该流程定义的详情页。

**预期结果**
* 页面上方是流程图，右上角是工具栏；下方是信息面板，第一行是**定义信息条**，其下是当前视图的页签栏。
* 定义信息条列出名称、版本、挂起状态、租户、版本标签、历史保留时间与流程定义 ID；放不下的格子收进右端的「…」。ID 可直接点击复制。
