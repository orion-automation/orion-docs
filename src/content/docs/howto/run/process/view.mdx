---
title: 如何切换视图、版本与刷新
description: 如何在 ORION 流程定义详情页切换进行时与历史视图、选择定义版本、刷新数据并调整信息面板。
---

**前置条件**
* 已进入目标流程定义的详情页，见 [如何打开流程定义详情](/howto/run/process/)。

**操作步骤**
1. 在工具栏最右端的分段控件上点「进行时」或「历史视图」，切换两套数据。
2. 点旁边的版本按钮展开版本列表，选中要查看的版本（行内带故障数、运行实例数与版本标签）。
3. 点「刷新」重新拉取；点「自动刷新」开启每 3 秒自动刷新，再点一次暂停。
4. 拖动信息面板顶部的横条可调整面板高度，点面板右端的箭头可收起或展开。

**预期结果**
* 两个视图切换后，页签栏会增删页签——进行时下是[流程实例、故障、调用的流程、调用的决策、Job 定义、人工任务、协作流程](/howto/run/process/runtime/)，历史下是[流程实例、故障、调用的流程、调用的决策、Job 日志、用户操作日志、外部任务日志、协作流程](/howto/run/process/history/)。版本与视图控件本身位置不动。
* 版本、故障数、运行实例数与工具栏上的挂起状态始终指向**当前选中的这一版**。

:::caution[先确认版本再动手]
工具栏上的动作大多只作用于当前选中的版本。切换版本后，页签数据与工具栏状态会一起换。
:::
