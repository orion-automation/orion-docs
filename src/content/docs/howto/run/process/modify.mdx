---
title: 如何编辑运行中实例
description: 如何在 ORION 流程定义详情用流程编辑给运行中的实例添加编辑指令，选择作用范围并执行。
---

**前置条件**
* 已进入目标流程定义的详情页，并切到**进行时视图**——「流程编辑」按钮只在这个视图出现。
* 编辑的对象是运行中实例的活动状态。

**操作步骤**
1. 点击顶部「流程编辑」，进入流程编辑页。
2. 在当前版本的图上点节点，选择要执行的编辑类型，按顺序添加编辑指令（如取消某个活动、跳过某个节点）。
3. 选择作用范围：手选一批实例，或拼一个实例条件；从实例详情进入时范围会锁在那一个实例上。
4. 核对请求预览与影响范围后执行。

**预期结果**
* 指令按顺序应用到匹配的实例；不完整的指令会被拦截并提示。
* 已锁定的实例不会被改动，摘要中单独列出。
