---
title: 如何启动流程
description: 如何在 ORION 流程定义详情点击「启动流程」，指定开始位置、填写启动参数与选项并确认创建实例。
---

**前置条件**
* 已进入目标流程定义的详情页；进行时与历史视图下都能看到这颗按钮。

**操作步骤**
1. 点击顶部「启动流程」，进入启动页。
2. 在「从哪开始」里选「默认开始节点」，或选「指定开始位置」并在图上点节点，指定在该活动之前、之后、沿某条连线、或对整个多实例开始。
3. 在「启动参数」里填写业务键与启动变量；单个变量可移除。
4. 在「启动选项」里按需勾选：跳过输入输出映射、跳过自定义监听器、返回变量。
5. 核对请求预览后确认启动。

**预期结果**
* 创建成功后页面显示新实例的关键信息；业务键存在时一并展示。
* 不指定开始位置时按流程默认起点开始。

:::caution[定义被挂起时起不来]
挂起状态下无法以这一版启动新实例，先到 [如何挂起与激活流程定义](/howto/run/process/suspend/) 激活。
:::
