---
title: 如何分析流程运行数据
description: 如何在 ORION 流程定义详情启动流程分析，读取节点耗时热力图，并下钻到异常节点的执行人与变量归因。
---

**前置条件**
* 已进入目标流程定义的详情页；进行时与历史视图下都能看到「分析」按钮。
* 同一版本需要**至少 2 个已完成的实例**才允许启动分析。

**操作步骤**
1. 点击顶部「分析」，进入流程分析页。
2. 点「启动分析」；已完成实例不足时页面会给出所需数量与当前数量，此时先去跑几个实例。
3. 等待分析完成——通常数十秒内完成；离开本页会暂停检查，再次进入时继续。
4. 完成后在「热力图指标」里切换平均耗时、中位耗时、P90 耗时、执行次数或异常指数，流程图上随之叠加节点热力图。
5. 点某个节点可看它的异常节点分析：执行人拆分、变量归因，以及该节点跑过的技能。

**预期结果**
* 分析记录保存在「分析记录」列表里，可随时读回上次结果。
* 状态有启动中、进行中、已完成、失败、超时等；查不到结果时可「重新检查」或「重新分析」。

:::note[样本太少得不出结论]
分析要算实例之间的到达与分散间隔，只有一个已完成实例时会直接拒绝启动。自动化节点通常没有执行人维度，变量归因会是空的。
:::
