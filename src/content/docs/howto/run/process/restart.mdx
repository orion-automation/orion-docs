---
title: 如何重启已结束实例
description: 如何在 ORION 流程定义详情把已结束的实例按指定版本从头再跑一遍，选择开始位置与执行策略。
---

**前置条件**
* 已进入目标流程定义的详情页，并切到**历史视图**——「流程重启」按钮只在这个视图出现。
* 重启的对象是已结束的实例。

**操作步骤**
1. 点击顶部「流程重启」，进入流程重启页。
2. 在图上点节点选择「从哪里重来」。
3. 搜索并勾选要重启的实例。
4. 选择目标版本，按需设置初始变量与执行策略（跳过输入输出映射、跳过自定义监听器、不含业务键等）。
5. 核对影响范围与请求预览后执行。

**预期结果**
* 被选实例按目标版本重新进入运行状态，新实例与旧实例并存。
* 空选择会被拦截并提示。
