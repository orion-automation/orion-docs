---
title: 如何挂起与激活流程定义
description: 如何在 ORION 流程定义详情挂起或激活当前版本，是否连带处理运行中的实例，以及设置执行时间。
---

**前置条件**
* 已进入目标流程定义的详情页。
* 作用于**当前选中的版本**，进行时与历史视图下都在；按钮文案随状态在「挂起定义」与「激活定义」之间切换。

**操作步骤**
1. 点击顶部的「挂起定义」或「激活定义」。
2. 核对提示里的流程名与版本——操作只影响这一版，其它版本不受影响。
3. 按需勾选「同时处理运行中的流程实例」：挂起时一并挂起正在运行的实例，激活时一并激活已挂起的实例。
4. 按需填写「执行时间」：留空表示立即执行，设置后引擎会在该时间点执行。
5. 点「挂起」或「激活」确认。

**预期结果**
* 定义信息条上的状态点随即更新；挂起后不能再以这一版启动新的流程实例。
* 已有实例在未勾选时不受影响，可在实例视图中复核。

:::caution[挂起与删除是两件事]
挂起只是让这一版停下，实例与历史都还在；删除才是不可撤销的清理，见 [如何使用更多操作](/howto/run/process/more/)。
:::
