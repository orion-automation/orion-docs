---
title: 如何使用更多操作
description: 如何在 ORION 流程定义详情的更多操作菜单里删除定义或实例、发送信号，并按视图选择对应条目。
---

**前置条件**
* 已进入目标流程定义的详情页。
* 点工具栏右端的「更多操作」（⋯）展开菜单；菜单项随当前视图变化。

**操作步骤**
1. 按当前视图选择菜单项：
   * **进行时视图**：删除流程定义、发送信号、删除运行实例；
   * **历史视图**：删除流程定义、删除已完成流程实例。
2. **删除流程定义**（两个视图都在）：删除当前选中的这一版，确认框中可勾选「同时删除该版本的流程实例与历史数据」。
3. **发送信号**（仅进行时）：填写信号名称（可附变量）后广播——所有正在等待该信号的处理器都会收到，可由该信号启动的流程也会因此启动。
4. **删除运行实例**（仅进行时）：先在「手选实例」与「条件查询」之间挑一种方式圈定范围，可填写删除原因，并按需跳过自定义监听器、子流程实例与输入输出映射。
5. **删除已完成流程实例**（仅历史）：同样两种圈定方式，额外可按结束时间范围收窄。
6. 在确认框中核对目标名称与影响面后提交。

**预期结果**
* 删除是**异步批处理**：提交成功后数据不会立刻消失，要等批处理作业执行完；提交会返回一个批处理 ID，可据此对账，并到 [如何跟踪批处理进度](/howto/run/batch/track/) 跟踪。
* 发送成功提示「信号 `{名称}` 已广播」——只代表信号发出去了，不代表有实例接到了。
* 列表与统计随即刷新；运行中实例的删除可在实例视图中复核。

:::danger[删除不可撤销]
删除前先确认影响范围。要暂停而不是清理，用 [如何挂起与激活流程定义](/howto/run/process/suspend/)。
:::
