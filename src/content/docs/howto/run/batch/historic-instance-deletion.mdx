---
title: 如何删除已完成流程实例
description: 如何在 ORION 新建批处理永久删除已结束的流程实例及其历史数据，填写删除原因并按历史条件圈定范围。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：已完成实例。来源：新建批处理。

**做什么**
* 永久删除已结束的流程实例及其历史数据（含活动、变量、任务记录），不可撤销。

**参数**
* **删除原因**——写入各实例的历史记录，便于后续审计，可留空。

**范围**
* 只按历史数据筛选，可按开始时间、结束时间等条件圈定。

:::danger[不可恢复]
删除的是完整历史轨迹。只想让记录不再被自动清理，用 [如何设置流程历史清除时间](/howto/run/batch/process-removal-time/)。
:::
