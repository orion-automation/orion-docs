---
title: 如何批量设置流程实例变量
description: 如何在 ORION 新建批处理为匹配的流程实例批量写入或覆盖同一组变量。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：运行中实例。来源：新建批处理。

**做什么**
* 为匹配的实例批量写入（或覆盖）同一组变量。

**参数**
* **要写入的变量**——至少一个键，否则该批处理不产生任何变更；同名变量将被覆盖。

**典型场景**
* 批量修正某个业务字段的取值，或给一批实例补上同一份标记。

:::caution[同名会覆盖]
提交前确认要写的键没有与实例上已有的变量重名，否则会被直接盖掉。
:::
