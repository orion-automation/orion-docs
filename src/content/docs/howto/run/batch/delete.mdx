---
title: 如何删除批处理
description: 如何在 ORION 批处理列表删除进行中或已完成的批处理，以及两种页签下不同的删除后果。
---

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」，并在左侧导航点击「批处理」。
* 删除不可撤销；「进行中」与「已完成」两个页签走的是不同的删除方式。

**操作步骤**
1. 在目标批处理行点「更多操作」→「删除」。
2. **进行中**的批处理：确认框可勾选「同时删除历史记录」；不勾选时只删批处理及其关联的作业与作业定义。
3. **已完成**的批处理：确认框直接写明后果，没有额外选项。
4. 核对后确认。

**预期结果**
* 记录从列表移除；**已经执行完的变更不会回滚**。
* 删除只作用于批处理本身，不撤销它对业务数据做过的事。

:::danger[先确认它跑完没有]
进行中的批处理删掉后，还没执行的作业不会再跑。只想让它停下，先确认状态再决定。
:::
