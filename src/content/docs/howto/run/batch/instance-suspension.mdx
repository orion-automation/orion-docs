---
title: 如何批量挂起或激活流程实例
description: 如何在 ORION 新建批处理批量挂起匹配的流程实例或把已挂起的实例恢复推进。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：运行中实例。来源：新建批处理，对应两张卡片。

**做什么**
* **挂起流程实例**：暂停匹配实例的推进——作业不再执行，人工任务不再产生。
* **激活流程实例**：恢复被挂起的实例，继续按流程推进。

**参数**
* 无。这一类只按范围挑对象，不需要额外填写。

:::note[与挂起定义不是一回事]
挂起的是**实例**，流程定义本身仍可启动新实例。要让整版停下，见 [如何挂起与激活流程定义](/howto/run/process/suspend/)。
:::
