---
title: 如何设置作业重试次数
description: 如何在 ORION 新建批处理把匹配作业的重试次数设为指定值，并设置重试到期时间。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：运行中实例。来源：新建批处理。

**做什么**
* 将匹配作业的重试次数设为指定值，使失败的作业可被再次执行。

**参数**
* **重试次数**（必填）——0 表示不再重试，后续失败将直接产生故障。
* **重试到期时间**——留空表示不改动原有的到期时间。

**典型场景**
* 故障已排除，需要把耗尽重试的作业重新推回队列。
