---
title: 如何批量迁移流程实例
description: 如何从 ORION 流程迁移页把运行中的流程实例迁到另一个版本，并在批处理列表跟踪其进度。
---

**前置条件**
* 从 [如何迁移流程实例](/howto/run/process/migrate/) 进入流程迁移页——这一类不在新建批处理的入口里。
* 作用面：运行中实例。来源：流程迁移页。

**做什么**
* 把运行中的流程实例从一个版本迁到另一个版本，按元素映射逐条对齐。

**为什么不放在新建入口里**
* 迁移要并排看两个版本的流程图，一个确认弹窗装不下。

**预期结果**
* 创建后同样出现在批处理列表里，按类型「流程实例迁移」跟踪进度，见 [如何跟踪批处理进度](/howto/run/batch/track/)。
