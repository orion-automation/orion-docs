---
title: 如何跟踪批处理进度
description: 如何在 ORION 批处理列表查看进行中与已完成的批处理，筛选、刷新并打开详情抽屉核对作业计数。
---

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」，并在左侧导航点击「批处理」。
* 至少已创建过一个批处理，见 [如何新建批处理](/howto/run/batch/)。

**操作步骤**
1. 在「进行中」页签查看当前批处理：作业号、类型、进度、执行人、开始时间与状态。
2. 切到「已完成」页签查看历史：作业数、结束时间与耗时。
3. 点工具栏「筛选」按作业号、类型、状态、执行人、开始时间区间收窄，或按「只看有失败作业的批次」「只看无租户的批次」过滤。
4. 点「刷新列表」拉取最新进度。
5. 点批处理行打开详情抽屉，核对进度、基本信息与作业定义。

**预期结果**
* 进度列随执行推进更新；完成后在「已完成」页签可查到耗时。
* 详情抽屉里的作业总数、已创建作业、剩余作业、已完成作业与失败作业合计应与进度一致。
* 失败会以「`{数量}` 失败」显示；状态列可能显示「已暂停」。
