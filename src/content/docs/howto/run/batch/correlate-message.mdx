---
title: 如何批量关联消息
description: 如何在 ORION 新建批处理向匹配的流程实例批量投递同一条消息，触发其等待中的消息事件。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：运行中实例。来源：新建批处理。

**做什么**
* 向匹配的实例批量投递同一条消息，触发其等待中的消息事件。

**参数**
* **消息名**——仅匹配正在等待该名称消息事件的实例，其余实例不受影响。
* **要写入的变量**——可留空（仅投递消息、不修改变量）；同名变量将被覆盖。

:::note[只叫得醒正在等的]
消息名对不上、或者实例当前没在等这条消息，它就不会被触发——这是预期行为，不是失败。
:::
