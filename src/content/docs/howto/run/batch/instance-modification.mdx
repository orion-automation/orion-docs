---
title: 如何批量修改流程实例
description: 如何从 ORION 流程编辑页对一批运行中实例执行流程编辑，并在批处理列表跟踪其进度。
---

**前置条件**
* 从 [如何编辑运行中实例](/howto/run/process/modify/) 进入流程编辑页——这一类不在新建批处理的入口里。
* 作用面：运行中实例。来源：流程编辑页。

**做什么**
* 在当前版本的流程图上点节点、按顺序添加编辑指令，作用到一批运行中实例。

**为什么不放在新建入口里**
* 它必须在图上选节点，与向导的形态不同；两个入口做同一件事只会让人不知道该点哪个。

**预期结果**
* 创建后同样出现在批处理列表里，按类型「流程实例修改」跟踪进度，见 [如何跟踪批处理进度](/howto/run/batch/track/)。
