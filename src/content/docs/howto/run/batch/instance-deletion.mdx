---
title: 如何删除运行中流程实例
description: 如何在 ORION 新建批处理删除仍在运行的流程实例，填写删除原因并选择要跳过的回执动作。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：运行中实例。来源：新建批处理。

**做什么**
* 删除仍在运行的流程实例，并连同其运行时与历史数据一起清理。

**参数**
* **删除原因**——写入历史记录，可留空。
* **跳过哪些回执动作**
  * 跳过自定义监听器——依赖其完成的补偿与通知将不会发生；
  * 跳过子流程——子流程不随主流程删除，将变为孤儿实例并继续运行；
  * 跳过输入 / 输出映射——不执行任务的输入输出映射。

**范围**
* 可按运行时属性筛选，也可按历史数据筛选。

:::danger[删除不可撤销]
只想让这一批停下来，用 [如何批量挂起或激活流程实例](/howto/run/batch/instance-suspension/)。
:::
