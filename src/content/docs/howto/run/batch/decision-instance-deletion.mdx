---
title: 如何删除已完成决策实例
description: 如何在 ORION 新建批处理永久删除已结束的决策实例及其评估记录。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：决策实例。来源：新建批处理。

**做什么**
* 永久删除已结束的决策实例及其评估记录，不可撤销。

**参数**
* **删除原因**——可留空。

**范围**
* 按历史决策实例的条件圈定；这一类没有「运行中」的数据来源，因为决策实例只有历史。

:::danger[不可恢复]
评估记录删掉后无法回看。只想推迟清理，用 [如何设置决策历史清除时间](/howto/run/batch/decision-removal-time/)。
:::
