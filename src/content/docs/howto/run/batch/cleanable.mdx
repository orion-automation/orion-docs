---
title: 如何查看待清理的批处理
description: 如何在 ORION 批处理的可清理页签按类型核对历史保留天数、已完成条数与下次清理会删掉的条数。
---

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」，并在左侧导航点击「批处理」。

**操作步骤**
1. 切到「可清理」页签。
2. 按「历史 TTL（天）」「已完成」与「可清理」三列核对哪些记录已过保留期。
3. 需要时点列头排序——这一报表只能按「已完成」条数排序。

**预期结果**
* 这一档是**报表**，一行代表一种批处理类型，不是一条批处理。
* 「可清理」= 该类型中已超过保留期、下次清理会被删掉的条数；历史 TTL 显示为「—」表示未配置，未配置的类型永远不会被自动清理。
* 清理由历史清理任务统一执行，触发方式见 [如何清理历史数据](/howto/run/audit/cleanup/)。
