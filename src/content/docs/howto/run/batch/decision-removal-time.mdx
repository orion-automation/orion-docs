description: 如何在 ORION 新建批处理为历史决策实例设置清除时间，按保留期、指定时刻或清空。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：决策实例。来源：新建批处理。

**做什么**
* 为匹配的历史决策实例设置清除时间，到期由历史清理作业统一删除。

**参数**
* **清除时间怎么定**，三选一，含义与 [如何设置流程历史清除时间](/howto/run/batch/process-removal-time/) 完全一致，只是落点在决策实例上。
