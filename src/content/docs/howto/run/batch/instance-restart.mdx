title: 如何批量重启流程实例
description: 如何从 ORION 流程重启页把已结束的实例按指定版本再跑一遍，并在批处理列表跟踪其进度。
---

**前置条件**
* 从 [如何重启已结束实例](/howto/run/process/restart/) 进入流程重启页——这一类不在新建批处理的入口里。
* 作用面：已完成实例。来源：流程重启页。

**做什么**
* 把已结束的实例按指定版本从头再跑一遍，新实例与旧实例并存。

**为什么不放在新建入口里**
* 它要在图上选「从哪里重来」，还要挑一批已完成的实例。

**预期结果**
* 创建后同样出现在批处理列表里，按类型「流程实例重启」跟踪进度，见 [如何跟踪批处理进度](/howto/run/batch/track/)。
