---
title: 如何设置批次历史清除时间
description: 如何在 ORION 新建批处理为历史批处理记录本身设置清除时间，到期由历史清理作业统一删除。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：批处理本身。来源：新建批处理。

**做什么**
* 为历史批处理记录设置清除时间，到期由历史清理作业统一删除。

**参数**
* **清除时间怎么定**，三选一，含义与 [如何设置流程历史清除时间](/howto/run/batch/process-removal-time/) 一致。

**说明**
* 这一类清理的是**批处理记录本身**，与它当初做过的事无关。
