---
title: 如何新建批处理
description: 如何在 ORION 运行模块用三步向导新建批处理：选操作卡片、定查询范围与执行对象、核对后创建。
---

批处理把「对一批同一件事」拆成三步向导：**查询范围 → 执行对象 → 确认**。

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。
* 明确目标对象的筛选条件，以及要执行的操作类型。

**操作步骤**
1. 在左侧导航点击「批处理」。
2. 点击「新建批处理」，在操作卡片里选一种。卡片按作用面分四组：**已完成实例、运行中实例、决策实例、批处理本身**；组内按常见程度排列。各类型的取舍见 [如何选择批处理类型](/howto/run/batch/types/)。
3. **查询范围**：选数据来源——「运行中的实例」按运行时属性筛选（流程定义、业务键、当前活动、事故等）；「按历史数据筛选」额外支持开始时间、结束时间这类只存在于历史记录里的条件。
4. **执行对象**：指定本批次的作用对象——「按查询范围执行」只提交查询条件，引擎在执行时按条件重新匹配；「手动选择实例」提交所选实例的 ID 列表。
5. 填写该操作特有的参数。
6. **确认**：核对范围面计数、参数摘要与请求预览，点「创建批处理」。

**预期结果**
* 向导三步可来回修改；范围内没有对象时给出提示，需返回上一步放宽条件。
* 创建后批处理进入「进行中」页签，引擎按计划分批执行。
* 未定义任何条件时会被拦截——只限定「已结束」等同于未限定，会匹配到全部对象。

:::caution[批量操作影响面大]
提交前务必在确认页核对范围面计数；不确定时先收窄条件，用少量对象验证。
:::
