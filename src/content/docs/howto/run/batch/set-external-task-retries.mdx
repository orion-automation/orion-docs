---
title: 如何设置外部任务重试次数
description: 如何在 ORION 新建批处理把匹配外部任务的重试次数设为指定值。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：运行中实例。来源：新建批处理。

**做什么**
* 将匹配的外部任务的重试次数设为指定值。

**参数**
* **重试次数**。

:::note[与作业重试的区别]
作用对象不同：[如何设置作业重试次数](/howto/run/batch/set-job-retries/) 改的是引擎里的作业，这一类改的是交给外部处理者的任务。
:::
