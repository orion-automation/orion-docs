---
title: 如何设置流程历史清除时间
description: 如何在 ORION 新建批处理为历史流程实例设置清除时间，按保留期自动计算、指定时刻或清空。
---

**前置条件**
* 已在运行模块打开新建批处理向导，见 [如何新建批处理](/howto/run/batch/)。
* 作用面：已完成实例。来源：新建批处理。

**做什么**
* 为匹配的历史流程实例设置清除时间，到期由历史清理作业统一删除。

**参数**
* **清除时间怎么定**，三选一：
  * **按保留期自动计算**——依据流程定义上的历史保留期计算；未配置保留期的实例会被跳过。
  * **指定一个时刻**——到期后由历史清理作业删除；早于当前时刻即视为立即清理。
  * **清空（不再自动清理）**——把清除时间置空，这批历史数据不再被自动清理；本操作不删除任何数据。
