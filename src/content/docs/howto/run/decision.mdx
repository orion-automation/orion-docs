决策面板管理已部署的决策资源：先在列表定位定义，再进详情看模型与历史评估记录。

## 1. 打开决策面板

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。
* 目标决策已随部署上线；若还没上线，先按 [如何部署与管理资源](/howto/run/deployment/) 部署。

**操作步骤**
1. 在左侧导航点击「决策」。
2. 页首在「决策定义」与「决策需求定义」两个页签间切换。
3. 用搜索框按名称或 Key 过滤，点「刷新列表」拉取最新数据。

**预期结果**
* 「决策定义」页签列出名称、Key、版本；「决策需求定义」页签列出对应的需求数量。
* 点击列头可按该列排序。

## 2. 查看决策模型详情

**操作步骤**
1. 点击列表中的目标决策，进入详情页。
2. 画布加载决策模型；画布下方是一条横向信息栏，列出名称、决策定义 Key、版本、版本标签、租户、历史保留时长、决策定义 ID 与决策部署 ID——随窗口宽度折行，UUID 类字段默认折叠成小箭头。
3. 需要时点抬头的「收起信息面板」或「展开信息面板」调整画布视野，也可拖动分隔条改变信息栏高度。
4. 用「模拟」试算决策，或点「导出 DMN」下载模型文件。

**预期结果**
* 画布显示当前版本的决策表/DMN 图；若该版本没有可展示的决策内容，会给出明确提示。
* 信息栏字段可用于与部署记录、流程实例对账。

## 3. 查看决策历史

**操作步骤**
1. 在详情页向下滚动——「决策历史」就在同一页画布下方的区块，不是页签（本页只有这一个区块标签，往下滚就能看到）。
2. 用抬头右侧的「决策实例 ID」搜索框粘贴完整实例 ID 定位；表格按评估时间倒序，可核对决策实例 ID 与关联的流程实例。
3. 需要清理记录时点「删除决策历史实例」并确认。

**预期结果**
* 历史按评估时间列出每次决策的输入结果；关联流程实例可跳回 [如何监控流程定义与实例](/howto/run/process/) 继续排查。

:::caution[删除历史不可撤销]
删除决策历史实例会移除评估留痕，用于对账的记录无法恢复，执行前确认范围。
:::
