部署面板管理已上线的资源与版本：新建部署、查看资源内容、按需重新部署或删除。

## 1. 新建部署

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。
* 已准备好要上线的资源文件。

**操作步骤**
1. 在左侧导航点击「部署」。
2. 点击「部署」按钮打开新建对话框。
3. 把文件拖入拖放区，或点击选择文件（可多选）。
4. 按需填写 **部署名称**（选填；不填则按资源推导）、**租户 ID**（选填）与 **生效时间**（选填）。
5. 按需勾选 **只部署发生变化的资源** 或 **同名同内容时不再重复部署**。
6. 点「部署」提交。

**预期结果**
* 提示「`{名称}` 已部署」，列表出现新部署。
* 支持的资源类型：BPMN、DMN、表单、连接器。

:::danger[BPMN 必须声明历史保留时间]
流程 BPMN 未声明 `historyTimeToLive`（历史保留时间）时，部署会被引擎直接拒绝并报 **ENGINE-12018**（TTL cannot be null——历史清理需要 TTL 才能工作）。部署前先在流程模型里补上该属性；报错信息会列出可选方案，且会指明出错的资源名与行号、列号，照着修正后重新提交。
:::

## 2. 查看部署内容

**前置条件**
* 目标部署已在列表中；可用顶部搜索框按部署名称过滤。

**操作步骤**
1. 点击列表中的目标部署，右侧滑出详情抽屉。
2. 在「部署资源」区选择要查看的资源。
3. 按需在「图形」与「XML」两种视图间切换；需要留档时点「下载」。
4. 点右上角可全屏查看，看完点「关闭」收起。

**预期结果**
* 图形视图渲染流程或决策图；XML 视图展示源文件。
* 不支持预览的资源类型会提示可下载查看；空部署提示「该部署下没有资源」。

## 3. 重新部署

**适用场景**：同一批资源要出一个新版本，同时保留原部署不动。

**操作步骤**
1. 在列表中点击目标部署行的「更多操作」菜单。
2. 选择「重新部署」。
3. 在资源列表中勾选要重新部署的资源，需要时点「全选」。
4. 点「重新部署」提交。

**预期结果**
* 提示「`{名称}` 已重新部署」，列表出现一个新部署；原部署保持不变。
* 资源加载失败时抽屉内给出错误提示，可重试。

## 4. 删除部署

**前置条件**
* 删除不可撤销；若部署下仍有流程在跑，删除前先确认影响。

**操作步骤**
1. 在列表中点击目标部署行的「更多操作」菜单。
2. 选择「删除部署」，在确认框中核对部署名称。

**预期结果**
* 提示删除结果，列表移除该部署。确认框文案会明确「将被删除，无法撤销」。

:::danger[删除前先确认引用]
删除部署会连带移除其下的资源定义。仍在运行的实例与未完成的作业可能因此失去关联，先在 [如何监控流程定义与实例](/howto/run/process/) 核对引用。
:::

## 5. 检索与排序

**操作步骤**
1. 顶部搜索框按部署名称过滤。
2. 点「刷新列表」拉取最新数据；点列头按该列排序。

**预期结果**
* 列表展示名称、来源、部署时间与部署 ID；条件变化后结果自动更新。
