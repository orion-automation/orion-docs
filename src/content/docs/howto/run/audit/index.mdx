---
title: 如何审计用户操作日志
description: 如何在 ORION 运行模块按常规与作用对象条件查询用户操作记录，查看操作详情并给记录加备注。
---

用户操作日志回答一个问题：**谁在什么时候改了什么**。

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。

## 1. 查询操作记录

**操作步骤**
1. 在左侧导航点击「用户操作日志」。
2. 点「筛选」打开面板，按需填写：
   * **常规**：操作人、操作类型、对象类型、分类、变更字段、时间晚于 / 时间早于；
   * **作用对象**：流程实例 ID、流程定义 ID、流程定义 Key、执行流 ID、任务 ID、作业 ID、作业定义 ID 等。
3. 点「重置」清空条件；点「刷新」拉取最新记录。

**预期结果**
* 列表按时间排序展示时间、操作人、操作、对象、变更与备注六列。
* 修改条件后结果自动更新。

## 2. 查看操作详情并加备注

**操作步骤**
1. 点击目标记录，右侧滑出「操作详情」。
2. 在「这次操作」区查看变更内容，在「标识与关联」区核对记录 ID、根流程实例 ID 与清理时间。
3. 需要留痕说明时，在「备注」区填写并保存。

**预期结果**
* 备注保存后回写到列表的备注列。
* 提示会说明：这是一条「改动备注」的留痕，不是业务数据变更。

:::note[与流程定义页的操作日志不是一回事]
流程定义详情的历史视图里也有一页「用户操作日志」，那一份只统计**当前这一版**的记录；这里是全站口径，见 [如何查看历史视图](/howto/run/process/history/)。
:::
