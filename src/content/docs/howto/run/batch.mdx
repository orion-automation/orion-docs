批处理把「对一批实例做同一件事」拆成三步向导：查询范围 → 执行对象 → 确认。本篇覆盖创建、跟踪与清理。

## 1. 新建批处理

**前置条件**
* 已登录 ORION，从顶部「打开应用菜单」进入「运行」。
* 明确目标实例的筛选条件，以及要执行的操作类型。

**操作步骤**
1. 在左侧导航点击「批处理」。
2. 点击「新建批处理」，选择一种操作类型：**批量修改、批量重启、批量取消、迁移**。
3. **查询范围**：选择数据来源——「运行中的实例」或「按历史数据筛选」。
4. **执行对象**：填写筛选条件与该操作特有的参数（如变量、消息名、重试次数）。
5. **确认**：核对范围面、重试次数、变量与消息名摘要，提交创建。

**预期结果**
* 向导三步依次推进，「上一步 / 下一步」可来回修改。
* 创建后批处理进入「进行中」页签，引擎按计划分批执行。

:::caution[批量操作影响面大]
提交前务必在确认页核对范围面计数；不确定时先收窄条件，用少量实例验证。
:::

## 2. 跟踪执行进度

**操作步骤**
1. 在「进行中」页签查看当前批处理：作业号、类型、进度、执行人、开始时间与状态。
2. 切到「已完成」页签查看历史：作业数、结束时间与耗时。
3. 需要时点「刷新」拉取最新进度；用搜索框按作业描述或执行人过滤。

**预期结果**
* 进度列随执行推进更新；完成后在「已完成」页签可查到耗时。

## 3. 暂停、取消与删除批处理

**前置条件**
* 暂停与取消只对进行中的批处理有意义。

**操作步骤**
1. 在目标批处理行点击「暂停」或「取消」，按提示确认。
2. 需要移除记录时，点「更多操作」→「删除此批处理」并确认。

**预期结果**
* 暂停后执行挂起，可再恢复；取消后未执行的作业不再继续。
* 删除后记录从列表移除，已执行的变更不会回滚。

## 4. 查看待清理的批处理

**操作步骤**
1. 切到「可清理」页签。
2. 按「历史 TTL（天）」「已完成」与「可清理」列核对哪些记录已过保留期。

**预期结果**
* 该页签列出可被历史清理回收的批处理；到期后由清理任务统一删除，见 [如何审计操作与清理历史](/howto/run/audit/)。
